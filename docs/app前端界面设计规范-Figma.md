# 维斯量化 TQuant — App 前端界面设计规范

> 本文档面向 Figma 设计师，包含登录界面、实时监控、选股宝典、模拟盘四个核心页面的完整 UI 规格。
> 所有数值、颜色、字体、间距均可直接用于 Figma 组件库搭建。

---

## 0. 设计系统

### 0.1 色彩 Token

| Token | 色值 | 用途 |
|-------|------|------|
| `--bg` | `#eef2f7` | 页面底色 |
| `--bg-soft` | `rgba(255,255,255,0.94)` | 面板底色 |
| `--bg-deep` | `#0b1422` | 深色面板底色（登录视觉区、任务栏） |
| `--bg-soft-muted` | `#f6f8fb` | 次级面板底色 |
| `--accent` | `#d6a55c` | 品牌金色，用于强调线 / 重点按钮 |
| `--accent-soft` | `rgba(214,165,92,0.12)` | 弱金色背景 |
| `--price-up` | `#c62828` | 涨 / 买入 / 正向（A股惯例：红涨） |
| `--price-down` | `#1f8b4c` | 跌 / 卖出 / 负向（A股惯例：绿跌） |
| `--price-flat` | `#162235` | 平盘 |
| `--warning` | `#f59e0b` | 警告色 |
| `--text` | `#162235` | 主文字色 |
| `--muted` | `#66758a` | 次级文字色 |
| `--line-strong` | `rgba(100,116,139,0.18)` | 面板边框 |
| `--shadow` | `0 6px 18px rgba(15,23,42,0.06)` | 面板投影 |
| `--radius-md` | `10px` | 面板圆角 |

### 0.2 字体

| 层级 | 字体 | 大小 | 字重 | 行高 | 用途 |
|------|------|------|------|------|------|
| H1 | Inter / System | 28-42px | 700 | 1.08 | 页面主标题 |
| H2 | Inter / System | 20-24px | 700 | 1.2 | 面板标题 |
| Body | Inter / System | 14px | 400 | 1.5 | 正文 |
| Caption | Inter / System | 11-12px | 500-800 | 1.3 | 辅助文字 / 标签 |
| Mono | IBM Plex Mono | 14px | 500 | 1.3 | 价格 / 数字 / 代码 |

### 0.3 间距体系

| Token | 值 | 用途 |
|-------|-----|------|
| `--space-2` | 8px | 紧凑间距（标签组内） |
| `--space-3` | 12px | 面板间距 / 卡片间距 |
| `--space-4` | 16px | 组件内间距 |
| `--space-5` | 20-22px | 面板内边距 |

### 0.4 通用组件库

五个核心面板在所有页面间共享：

| 组件 | 用途 | 关键属性 |
|------|------|----------|
| **StockCard** | 股票卡片 | 名称 + 代码 + 价格 + 涨跌幅 + 评分 + 风险等级 + 操作按钮 + 标签徽章 |
| **MetricGrid** | 指标条 | 水平排列的 N 个 Metric 卡片，label + value + tone 着色 |
| **PanelTitle** | 面板标题栏 | 左侧标题文字 + 右侧操作按钮组 |
| **InfoPill** | 信息药丸 | label: value 对，灰色底圆角胶囊 |
| **StockDetailDialog** | 股票详情弹窗 | 全屏覆盖弹窗，含 MiniKline 图表 + 多维度数据 |

## 1. 登录界面

### 1.1 页面概述

全屏双栏布局。左侧为品牌展示与盘中数据预览（深色背景），右侧为登录表单（浅色背景）。用户首次进入或 Token 过期时展示。


## 2. 实时监控

盘中实时监控面板，展示全策略优先级榜单、市场宽度、持仓做T信号。数据每 10 秒自动刷新。

### 2.2 整体布局

```
┌────────────────────────────────────────────────────────────────┐
│  盘中监控摘要（全宽）                                            │
│  [指标条 × 5]  [市场宽度条]                                     │

│  LEFT (1fr)                  │  RIGHT (1fr)                     │
│  全策略优先级榜               │  已持仓做T信号扫描               │
│  [标题+按钮]                  │  [标题]                          │
│  [方向/状态/板块/宽度/风险]    │  [StockCard × N]                │
│  [策略家族条]                  │                                  │
│  [StockCard × N (最多12)]     │                                  │
├──────────────────────────────┴─────────────────────────────────┤
│  录入底仓约束（侧边栏）                                          │
│  [表单 × 6列] [保存按钮]                                        │

```
```
grid-template-columns: 390px minmax(0, 1fr);
```
