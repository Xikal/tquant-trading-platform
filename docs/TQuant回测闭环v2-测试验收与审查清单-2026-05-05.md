## 当前状态

- 当前后端仍是 legacy `/backtests` 分钟级回测，定义在 `app.api.routes.research`。
- v2 要求的新 `app.api.routes.backtests` 已有骨架，并已注册到主 API router。
- v2 要求的新 `app.services.backtest.*` 已有 engine/broker/portfolio/data provider 骨架。
- 当前测试结果为 10 个 v2 合同点通过、4 个 v2 合同点 `xfail`，`xfail` 均为尚未完成或文档/实现不一致的审查点。

## 当前 xfail 合同点

- 文档示例使用 `strategies`、`initial_capital`、`execution_model`、`risk_limits` 顶层字段；当前 schema 使用 `strategy_keys`、`initial_cash`，并把执行/风控参数放入 `params`。
- `DailyBarDataProvider` 尚未暴露 dataset manifest hash 和 `adjustment_method="forward"`。
- `BacktestEngine.run` 尚未接受 cancel token，也不直接返回 `cancelled`/partial 语义。
- `BacktestEngine` 当前返回内存结果，尚未持久化 manifest、quality、trade、equity；持久化仍需要 worker/job 层打通。

## 审查门槛

- v2 路由必须注册到 `app.api.router.api_router`，路径统一为 `/api/backtests/*`。
- v2 回测必须异步，不允许 HTTP 请求同步跑完整回测。
- v2 结果必须包含 `code_version`、`strategy_version`、`fee_model_version`、`data_version_hash`。
- 数据质量问题不能阻塞回测，但必须写入质量表并出现在结果摘要。
- 交易明细必须包含手续费、印花税、过户费、净额、策略、持仓天数和收益字段。
- 净值输出必须包含日期、NAV、现金、市值、回撤和基准净值。
- 取消任务必须保留已写入明细，不能删除中间产物。
