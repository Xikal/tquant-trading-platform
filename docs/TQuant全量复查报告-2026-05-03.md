### 1.1 并发保护详细验证

`account.py:37-47` 实现了 `get_account(account_id, for_update=True)` 使用 `SELECT ... FOR UPDATE`：

```python
def get_account(self, account_id: int, *, for_update: bool = False) -> PaperAccount:
    if for_update:
        account = self.db.execute(
            select(PaperAccount).where(PaperAccount.id == account_id).with_for_update()
        ).scalars().one_or_none()
```

`order.py:129` 在 `_precheck` 中调用 `check_balance_locked` → `get_account(for_update=True)`，锁在事务内持续到 commit。因此验收项 2.9（模拟盘事务边界）的状态已从 ❌ 改善为 ✅。
