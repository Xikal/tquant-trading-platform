## 1. 总体结论

认可当前系统决策：`recommend_small_traffic_observation=false` 是正确的。

当前策略只适合继续 Shadow/Paper，不应进入小流量生产观察，更不能替换生产排序。`front_row_weighted` 的收益方向有改善迹象，但证据还不够硬，尤其是信号日留存不足、样本外样本太薄、未来函数证据不够字段级、报告口径仍有误导风险。

最终判断：

- `front_row_weighted`：继续 Shadow/Paper，暂不生产。
- `front_row_only`：禁止作为生产硬过滤，只能作为对照。
- `near_entry`：只进入观察池，不进入生产收益排行。
- 生产排序：不得替换。

## 2. 收益真实性审查

收益提升不能直接按表面数值采信。

表面上看，`front_row_weighted` 的真实组合收益明显优于 baseline：

| 指标 | baseline | front_row_weighted |
|---|---:|---:|
| 真实组合 max5 | 22.17% | 111.73% |
| 真实组合 max10 | 29.21% | 67.99% |
| 每日信号等权复利收益 | -6.23% | 388.51% |
| PF | 1.18 | 2.19 |
| 平均单笔 | 0.261% | 1.074% |

但这些结果不能直接证明策略已可生产，主要原因如下：

1. 样本筛选放大收益
   样本从 `4792` 缩到 `1544`，信号日从 `364` 缩到 `191`。收益提升很可能同时来自“剔除大量低质量样本”和“保留下来的样本更集中”，不能简单视为稳定 Alpha。

2. OOS 样本太薄
   JSON 季度拆分显示 `front_row_weighted` 在 2026Q2 只有 `6` 个样本。这个样本量没有样本外证明力，不能支持生产观察。

3. 每日信号等权复利收益仍容易被误读
   `388.51%` 是每日信号等权复利收益，不是真实账户收益。即使报告已经改名，仍应在主表弱化展示，避免被当成实盘组合收益。

4. 幸存者偏差未充分排除
   需要确认股票池是否包含退市、ST、停牌、流动性不足、长期不可交易标的。如果历史池只保留当前可见标的，收益会被明显高估。

5. 总表风险指标口径混用
   总表中的最大回撤、PF、平均单笔更像候选信号聚合口径；真实组合明细中 max5 最大回撤为 `-6.97%`，max10 为 `-4.34%`。候选口径和组合口径混在一张表里，会误导读者对风险的理解。

结论：收益“方向上值得继续验证”，但收益“幅度不可信”，不能作为生产准入依据。

## 3. 样本风险审查

当前样本覆盖构成阻断。

| 指标 | 数值 | 审查结论 |
|---|---:|---|
| 样本留存 | 32.22% | 偏低，说明候选池被大幅压缩 |
| 成交留存 | 31.83% | 偏低，真实可交易样本同步缩水 |
| 信号日留存 | 52.47% | 硬阻断，低于 75% 验收线 |
| 最长无票 | 19 天 | 单独看可接受，但结合信号日留存不足构成风险 |

信号日留存 `52.47%` 是最核心问题。它说明模型不是稳定增强排序，而是明显减少了可用交易日。对低吸/短线平台来说，这会带来三个实际问题：

- 用户长期无票，平台可用性下降。
- 样本外验证变得很薄，统计不稳定。
- 实盘观察期可能正好遇到无信号或少信号阶段，难以判断模型好坏。

75% 信号日留存门槛合理。当前未达标，因此 `signal_day_retention_below_75pct` 作为 blocker 是正确的。

## 4. max5 / max10 审查

同一候选池下 max5 收益高于 max10，不应简单解释为“持仓越少越好”，但足以说明当前不应开放 max10 生产。

真实组合明细：

| 指标 | max5 | max10 |
|---|---:|---:|
| 实际交易数 | 398 | 534 |
| 组合收益 | 111.73% | 67.99% |
| 最大回撤 | -6.97% | -4.34% |
| PF | 1.9073 | 1.8683 |
| 平均单笔 | 0.9674% | 0.9868% |
| 平均资金利用率 | 42.18% | 28.00% |
| 最大回撤恢复 | 21 笔恢复 | 截至结束尚未恢复 |

可能原因：

1. max10 单票资金槽位更小
   等权槽位下，max10 每票占用资金更低。即使交易数更多，资金利用率只有 `28.00%`，低于 max5 的 `42.18%`。

2. 新增候选边际质量不足
   max10 接受交易数从 `398` 增加到 `534`，但组合收益反而下降，说明后续候选没有贡献足够收益。

3. 排名尾部可能有衰减
   前 5 名候选质量可能明显高于第 6 至第 10 名。需要做 production_score 排名分桶验证。

4. 回撤恢复状态更差
   max10 最大回撤虽然数值更小，但截至回测结束未恢复，这说明扩仓后的组合路径存在未闭合风险。

审查结论：

- 当前 Paper 主口径应优先保留 max5。
- 不建议生产开放 max10。
- 不能仅凭当前结果永久确定最大持仓为 5，还需要补“排名边际收益衰减”和“不同市场状态下 max5/max10 对比”。

## 5. front_row_only 审查

`front_row_only` 足以明确禁止作为生产硬过滤方案。

关键数据：

| 指标 | front_row_only |
|---|---:|
| 样本留存 | 4.05% |
| 成交留存 | 3.93% |
| 信号日留存 | 24.18% |
| 最长无票 | 42 天 |
| max5 真实组合 | 28.26% |
| max10 真实组合 | 13.72% |

审查结论：

- 样本留存 `4.05%` 已经不是稳定生产策略，而是极窄事件筛选。
- 信号日留存 `24.18%` 会导致大量交易日无可用信号。
- 最长无票 `42` 天对短线平台不可接受。
- max10 收益低于 baseline，扩仓后失效明显。

因此，`front_row_only` 只能作为对照实验，不得作为生产硬过滤。

## 6. near_entry 审查

`near_entry` 不进生产收益排行是正确的。

当前规则：

- `production_score` 只允许 `buy_now` / `soft_buy_now` 生成。
- `near_entry_production_score_count=0`。
- `near_entry` 只能生成 `watch_score`，进入观察池。

这个设计合理。`near_entry` 本质是“接近买点”，不是可立即执行的生产信号。如果把它纳入生产收益排行，会把观察提前量误包装成可交易信号，放大收益并污染生产口径。

后续应单独建立 near_entry 观察池指标：

- near_entry 转化为 buy_now / soft_buy_now 的比例。
- 平均等待天数。
- 未转化率。
- 转化后真实组合收益。
- 误报率。
- 观察池触发后的回撤风险。

## 7. 未来函数审查

当前 `future_leak_check=passed` 不足以放行。

现在的审计更像策略级声明，不是字段级证据。生产前必须补充字段级审计。

必须补证的字段：

- `leader_strength_rank`
- `leader_strength_score`
- `industry_rank`
- `industry_tier`
- `mainline_tier`
- `market_state`
- `sector_heat`
- `risk_state`
- `distribution_risk_score`
- `entry_distance_pct`
- `execution_ready`
- `multi_timeframe_resonance_score`
- `main_force_advice`

必须输出的字段级证据：

| 审计项 | 要求 |
|---|---|
| signal_date | 每条信号的信号日 |
| feature_asof_date | 每个特征的数据截止日 |
| feature_generated_at | 特征生成时间 |
| decision_generated_at | 信号决策生成时间 |
| return_start_date | 收益计算开始日期 |
| max_time_offset | 特征相对信号的最大时间偏移 |
| violation_count | `feature_time > signal_time` 必须为 0 |
| fallback_count | 空值回退、默认值回退数量 |

判定标准：

- 所有生产评分特征必须满足 `feature_time <= signal_decision_time`。
- 收益计算必须从信号日之后开始。
- 不允许使用收盘后才知道的状态去解释盘中或当日买点。
- 市场状态、板块热度、前排强度、风险状态都必须能追溯到信号日及以前。

## 8. 过拟合审查

当前时间切分方向正确，但强度不足。

已做：

- train：`2024Q3-2025Q4`
- validation：`2026Q1`
- oos：`2026Q2`
- 禁止随机切分
- 声明不按 OOS 结果反向调参

不足：

1. OOS 样本太少
   2026Q2 只有 `6` 个 front_row_weighted 样本，不足以证明泛化。

2. 缺少 walk-forward
   需要滚动训练/验证/样本外评估，避免单次切分偶然有效。

3. 缺少市场状态分层
   必须分别验证牛市、震荡、退潮、缩量、快速轮动、风险释放等环境。

4. 缺少参数冻结后的再验证
   当前权重虽然声明来自固定开发方案，但仍需要冻结参数后独立再跑。

5. 缺少行业和策略来源集中度检查
   同策略日超限跳过较高，说明候选可能集中在少数策略或少数行情结构。

过拟合审查结论：

当前只能说明“历史筛选后表现好”，不能证明“未来稳定有效”。

## 9. 报告展示审查

当前报告有明显展示误导风险。

### 9.1 front_row_weighted_max5 / max10 命名误导

`front_row_weighted_max5` 和 `front_row_weighted_max10` 两行使用同一候选池，样本、成交、信号日、每日信号等权复利完全一样。这容易让读者误以为是两个不同策略变体。

建议改成：

1. 候选池对比表
   使用 `front_row_weighted_candidate_pool` 一行，展示样本、成交、信号日、留存、最长无票、每日信号等权复利。

2. 真实组合回测表
   在同一候选池下展示 max5 / max10：

| 候选池 | 持仓上限 | 交易数 | 资金利用率 | 组合收益 | 最大回撤 | PF | 平均单笔 | 回撤恢复 |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| front_row_weighted | max5 | 398 | 42.18% | 111.73% | -6.97% | 1.91 | 0.967% | 21 笔恢复 |
| front_row_weighted | max10 | 534 | 28.00% | 67.99% | -4.34% | 1.87 | 0.987% | 未恢复 |

### 9.2 候选信号口径和真实组合口径混用

总表中“最大回撤 / PF / 平均单笔”应标注清楚是候选信号口径还是组合口径。否则读者会把候选信号回撤误认为真实组合回撤。

### 9.3 每日信号等权复利收益应降权展示

该指标适合衡量信号质量，但不适合放在主结论最醒目位置。建议主结论优先展示真实组合收益、资金利用率、回撤、PF、交易数、信号日留存。

## 12. 最终建议

最终建议：继续 Shadow/Paper，不进入小流量观察。

理由：

1. 信号日留存 `52.47%` 明确低于 75% 准入线。
2. OOS 2026Q2 只有 `6` 条样本，样本外证据不足。
3. 收益提升可能被样本筛选和口径展示放大。
4. 当前 future_leak_check 缺少字段级审计。
5. max5/max10 展示方式容易误导。
6. front_row_only 已证明不适合生产硬过滤。

保守结论：

- `front_row_weighted`：继续验证，不生产。
- `front_row_only`：禁止生产硬过滤。
- `near_entry`：仅观察池。
- 下一步重点：字段级未来函数审计、完整 24 个月样本、walk-forward、市场状态分层、报告口径修正。
