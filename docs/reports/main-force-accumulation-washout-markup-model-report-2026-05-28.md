## 1. 结论摘要

可以建设“主力入场建仓、洗盘、拉升”的买点模型，但必须把“主力行为”定义为可回测的量价代理信号，而不是主观判断。

核心结论：

- 近两年日线数据已经覆盖全 A 主要股票，具备初步建模基础。
- 仅凭日线可以识别“吸筹区、洗盘区、突破拉升前夜”的结构，但买点精度仍受限于缺少逐笔、盘口、龙虎榜、真实资金流等细粒度数据。
- 模型第一版应做“候选过滤 + 买点评分 + Shadow 验证”，不能直接自动交易。
- 防未来函数必须作为硬门槛：未来 20/40 日涨幅只能用于标签，不能进入特征。
- 防过拟合必须使用时间切分、walk-forward、purged gap、分市场状态验证和参数稳定性测试。

推荐第一版模型：

1. 先用规则识别“潜在主力行为结构”。
2. 再用 LightGBM/XGBoost 等表格模型对规则候选排序。
3. 最终输出买点等级：`observe`、`wait_confirm`、`buy_probe`、`buy_confirmed`、`blocked`。
4. 所有信号先进入模拟盘/Shadow，不直接进入实盘或自动买入。

## 4. 模型目标定义

模型名称建议：

`main_force_accumulation_washout_markup`

中文名：

主力建仓洗盘拉升买点模型

模型目标：

- 找到已经出现资金介入迹象、完成洗盘或接近洗盘结束、后续有较大拉升概率的股票。
- 重点不是追最高涨幅，而是识别“可交易、可止损、可验证”的买点。

模型不做：

- 不直接判断“某只股票一定有主力”。
- 不预测必涨。
- 不直接下单。
- 不绕过现有低吸、风控、模拟盘和自动交易约束。

输出：

```json
{
  "symbol": "000000",
  "model": "main_force_accumulation_washout_markup",
  "stage": "accumulation | washout | markup_confirm | distribution_risk",
  "action": "observe | wait_confirm | buy_probe | buy_confirmed | blocked",
  "score": 0.0,
  "confidence": 0.0,
  "buy_zone": [0.0, 0.0],
  "stop_loss": 0.0,
  "take_profit_plan": [],
  "reasons": [],
  "risk_flags": [],
  "feature_time": "YYYY-MM-DD",
  "model_version": "v1"
}
```

## 5. 三阶段结构定义

### 5.1 建仓阶段

可观测代理：

- 股价处于 60 日或 120 日区间的中低位。
- 下跌趋势趋缓，低点不再明显下移。
- 成交额较前期抬升，但价格没有大幅上涨。
- 阴线下跌时成交量不再持续放大。
- 阳线反弹时成交额恢复较快。
- 板块开始有强度，但个股尚未明显主升。

规则示例：

- 60 日位置分位在 20%-65%。
- 20 日成交额 / 60 日成交额 > 1.05。
- 20 日振幅在 10%-35%，过小代表没资金，过大代表波动失控。
- 最近 10 日低点不再创新低，或创新低后快速收回。
- 非 ST、非退市、非停牌、20 日均成交额 >= 5000 万。

### 5.2 洗盘阶段

可观测代理：

- 前面已有一段放量上涨或异动。
- 随后回踩 5/10/20 日均线、VWAP 或前高平台。
- 回踩幅度足够但不破结构。
- 回踩成交量收缩，或放量下跌后能快速收回。
- 下影线、缩量阴线、假跌破收回等承接迹象出现。

规则示例：

- 近 20 日最大回撤在 -6% 到 -18%。
- 回踩低点不跌破前一平台低点或 20 日线过多。
- 回踩日成交额低于前一波拉升均额。
- 近 3 日出现至少 1 日收盘收回关键位。
- 当日收盘不追高，优先在回踩确认或重新站回关键位后买。

### 5.3 拉升确认阶段

可观测代理：

- 缩量洗盘后重新站回关键均线、平台高点或 VWAP。
- 成交额温和放大，不是极端爆量出货。
- 板块强度同步提升。
- 市场状态不是退潮或极弱。
- 龙头或同板块强势股没有明显破位。

规则示例：

- 收盘重新站上 MA5/MA10/平台关键位。
- 当日成交额 / 20 日均额在 1.1-2.5，避免过度爆量。
- 当日涨幅在 1%-7%，避免涨停追高。
- 板块近 3-5 日强度靠前。
- 市场宽度不处于明显弱势。

## 6. 精准买点设计

买点不应只有一个，而应分三类。

### 买点 A：洗盘低吸买点

适合：

- 建仓迹象已有。
- 洗盘回踩到关键支撑。
- 风险收益比好。

触发：

- 回踩 MA10/MA20 或前平台上沿附近。
- 近 10 日最大回撤 -6% 到 -15%。
- 当日缩量或量能低于前 5 日均量。
- 收盘未跌破结构止损位。

优点：

- 买点低，止损近。

缺点：

- 容易买早，需要二次确认。

建议动作：

- `buy_probe`，小仓试买。

### 买点 B：假跌破收回买点

适合：

- 洗盘日盘中跌破关键位。
- 收盘或次日重新收回。

触发：

- 盘中跌破 MA10/MA20/平台低点。
- 收盘收回关键位，或次日放量站回。
- 下跌日未出现连续放量失控。

优点：

- 洗盘结束信号更清晰。

缺点：

- 若板块退潮，假收回会失败。

建议动作：

- `buy_confirmed`，但仍需板块和市场确认。

### 买点 C：突破回踩确认买点

适合：

- 已突破平台。
- 首次回踩不破。
- 板块仍强。

触发：

- 突破 20 日平台后 1-5 日内回踩。
- 回踩不破平台上沿。
- 缩量回踩后重新站上 5 日线或分时 VWAP。

优点：

- 确认度高。

缺点：

- 成本较高，容易被假突破诱多。

建议动作：

- `buy_confirmed`，仓位不宜过大。

## 7. 特征体系

### 7.1 量价结构特征

- 20/40/60 日涨跌幅。
- 10/20/60 日最大回撤。
- 20 日振幅。
- 20 日波动率。
- 收盘价在 60 日区间的位置。
- 收盘价到 MA5/MA10/MA20/MA60 的距离。
- 是否站回 MA5/MA10/MA20。
- 是否突破 20/60 日平台。
- 是否假跌破后收回。

### 7.2 成交额和量能特征

- 当日成交额 / 20 日均额。
- 5 日均额 / 20 日均额。
- 20 日均额 / 60 日均额。
- 上涨日成交额 / 下跌日成交额。
- 回踩日成交额收缩比例。
- 放量滞涨标记。
- 爆量长上影标记。

### 7.3 洗盘质量特征

- 回踩幅度是否适中。
- 回踩是否缩量。
- 是否不破平台低点。
- 是否跌破后收回。
- 是否低点抬高。
- 是否出现下影承接。
- 是否连续阴线后放量阳线修复。

### 7.4 板块与市场特征

- 所属板块 3/5/10 日相对强度。
- 板块成交额变化。
- 板块涨停/大涨股票数量。
- 板块龙头是否破位。
- 市场宽度。
- 情绪温度。
- 龙头强度。
- market pulse 状态。

### 7.5 风险过滤特征

- 是否 ST。
- 是否停牌后复牌。
- 是否临近涨跌停。
- 20 日成交额是否不足。
- 是否连续一字板。
- 是否高位爆量长上影。
- 是否监管/退市/异常风险。
- 数据质量是否 fresh/verified。

## 8. 标签设计

标签只能用于训练，不能进入预测特征。

建议标签：

| 标签 | 定义 |
|---|---|
| `future_20d_up_30` | 信号后 20 日最高收盘涨幅 >= 30% |
| `future_40d_up_50` | 信号后 40 日最高收盘涨幅 >= 50% |
| `future_20d_drawdown` | 信号后 20 日最大不利波动 |
| `hit_stop_loss_5d` | 信号后 5 日内是否触发止损 |
| `best_entry_window` | 当前买、次日买、等回踩买哪个更优 |
| `profit_factor_bucket` | 后续收益质量分桶 |

主标签建议：

```text
positive = future_40d_up_50 == true
           and future_10d_drawdown > -12%
           and first_profit_before_stop == true
```

不能只用“未来涨幅大”当正样本，否则会选出很多无法承受回撤的票。

## 9. 防未来函数设计

硬规则：

- 任何 `future_*` 字段只能出现在标签生成阶段。
- 特征生成函数必须传入 `as_of_date`，只能读取 `trade_date <= as_of_date` 的数据。
- 市场状态、板块强度、龙头强度必须读取当日或历史快照，不能用当前最新状态回填历史。
- 训练、验证、测试按时间切分，禁止随机切分。
- 同一股票相邻样本要做去重或间隔，避免同一轮行情被重复学习。

测试要求：

- 构造未来价格字段，确认特征生成不会读取。
- 构造 T+1 数据，确认 T 日特征不可见。
- 构造最新板块强度，确认历史回测不会使用最新强度。
- 构造标签泄漏字段，模型训练前必须拦截。

建议代码层约束：

```text
FeatureFrame.as_of_date
FeatureFrame.max_source_date <= as_of_date
LabelFrame.label_start_date > as_of_date
```

## 10. 防过拟合设计

必须执行：

- 时间切分，不随机切分。
- Walk-forward：12 个月训练、3 个月验证、3 个月样本外测试，每月滚动。
- Purged gap：训练与测试之间留 5-10 个交易日隔离，避免持仓窗口重叠。
- 按市场状态分组验证：强势、震荡、弱势、退潮。
- 按行业分组验证：不能只在半导体/AI/通信里有效。
- 按市值/成交额分层验证：避免只适合小票或低流动性票。
- 参数稳定性：阈值附近 +/-10%-20% 仍要有效。
- 特征数量控制：第一版不超过 60 个特征。
- 模型复杂度控制：限制树深、叶子数、学习率和训练轮数。
- 输出 PBO 或等价过拟合风险指标。

上线门槛：

| 指标 | 门槛 |
|---|---|
| 样本外 PF | >= 1.35 |
| 样本外胜率 | >= 52% |
| 平均单笔收益 | > 成本 2 倍 |
| 最大回撤 | 不高于现有低吸基线 |
| 最差市场状态 | 不能显著亏损失控 |
| 参数稳定性 | 邻近参数仍有效 |
| Shadow 观察 | 至少 3 个月，推荐 6 个月 |

## 11. 与现有策略的关系

项目已有相关策略：

- 量能低吸。
- 主线中军 VWAP/MA5 回踩。
- 主线首分歧低吸。
- 主线涨停缩量回调。
- 龙头回踩波段。
- 长洗 N 字冲高。
- 短洗 N 字冲高。
- 涨停突破回踩。

本模型不是替代它们，而是形成上层过滤和打分：

```text
已有策略产生候选
        ↓
主力建仓洗盘拉升模型评分
        ↓
市场/板块/风险过滤
        ↓
输出买点等级和仓位建议
        ↓
模拟盘/Shadow 验证
```

建议先接入：

1. `leader_pullback_band`
2. `volume_shrink`
3. `breakout_support`
4. `n_pattern_long_wash`
5. `core_midcap_vwap_ma5_retrace`

不建议第一版接入弱策略：

- `sector_mainline_first_divergence_low_buy`
- `mainline_limitup_shrink_retrace_reclaim`
- `n_pattern_short_wash`

这些策略当前回测表现偏弱或回撤过大，应先作为研究样本，不进入生产买点增强。

## 12. 回测与评估方案

评估分三层：

### 12.1 规则基线

先实现纯规则版本：

- 建仓评分。
- 洗盘评分。
- 拉升确认评分。
- 风险扣分。
- 市场/板块过滤。

输出：

- 命中率。
- 平均收益。
- 最大回撤。
- 止损率。
- Profit Factor。
- 分市场状态表现。

### 12.2 模型排序

在规则候选上训练表格模型：

- 输入：T 日及以前特征。
- 标签：未来 20/40 日收益和回撤质量。
- 输出：上涨概率、回撤风险、买点等级。

不能全市场裸跑模型，否则噪声太大，过拟合风险高。

### 12.3 模拟盘 Shadow

每个交易日记录：

- 规则候选。
- 模型评分。
- 模型建议买点。
- 实际后续收益。
- 是否触发止损。
- 是否买早、买晚、错过。

Shadow 通过后才考虑进入模拟盘小仓。

## 13. 风控和失效条件

必须阻断：

- 市场处于退潮或极弱。
- 板块龙头连续破位。
- 个股高位爆量长上影。
- 连续涨停后开板放巨量。
- 20 日成交额不足。
- ST、退市、停牌、数据质量异常。
- 距离止损过远，风险收益比不足。
- 当日涨停附近追买。

止损：

- 洗盘低吸：跌破洗盘低点或 MA20。
- 假跌破收回：再次跌破收回位。
- 突破回踩：跌破平台上沿或突破日低点。

止盈：

- 首次快速上涨 8%-15% 分批止盈。
- 高位放量滞涨减仓。
- 板块强度下降减仓。
- 移动止盈保护利润。

## 14. 实施路线图

### M1：分析与数据集

- 建立大涨样本和对照样本生成脚本。
- 生成主力结构特征。
- 输出标签和数据质量报告。

### M2：规则模型

- 实现建仓评分、洗盘评分、拉升确认评分。

### M3：回测验证

- 对最近两年做 walk-forward。
- 输出分策略、分行业、分市场状态报告。

### M4：表格模型

- 训练 LightGBM/XGBoost。
- 输出特征重要性和过拟合风险。
- 与规则基线对比。

### M5：模拟盘 Shadow

- 每日记录候选和模型建议。
- 不改变真实交易动作。
- 观察 3-6 个月。

## 16. 最终建议

建议开发，但分阶段推进。

第一版不要直接追求“精准抓大牛股”，而要先做到：

1. 能识别大涨前常见的建仓、洗盘、拉升确认结构。
2. 能避开明显出货、退潮、流动性不足和数据异常。
3. 能严格避免未来函数。
4. 能在样本外仍优于现有低吸候选排序。
5. 能在模拟盘 Shadow 中持续记录命中和误判。

只有通过样本外和 Shadow 验证后，才允许作为生产策略权重的一部分。
