# 像素交易员 — 机甲风格（Mecha Pixel Trader）设计方案

## 1. 概述

将模拟盘"录入模拟委托"表单组件替换为一个像素级（pixel art）机甲角色，该角色在指挥舱内动态变化，根据市场状态、交易动作播放对应机甲动画与粒子特效。整体风格定位为 **赛博朋克像素机甲（Cyberpunk Mecha Pixel Art）**——冷峻金属质感 + 霓虹能量光效 + 像素颗粒感。

### 1.1 设计目标

- 用 Canvas 驱动的像素艺术机甲角色替代现有的 OrderEntryPanel 表单
- 机甲在不同状态下自动切换动画（待命、扫描、买入、卖出、休眠、冻结、超频）
- 买入/卖出动作触发机甲专属特效（核心熔炉红炽 / 散热阀绿焰）
- 保留委托录入能力：通过点击机甲或浮动按钮唤起紧凑的委托弹窗
- 与现有设计系统完全兼容，使用项目已有的 CSS Token

### 1.2 核心交互流程

```
页面加载 → 机甲进入待命状态（idle loop）
         ↓
    用户点击机甲 / 浮动 "+" 按钮 → OrderModal 弹出
         ↓
    填写委托信息 → 提交
         ↓
    机甲播放买入/卖出动画（1.5s） + 机甲粒子特效
         ↓
    机甲恢复工作状态，等待下一次交互
```

### 2.2 动画状态机

```
                  ┌──────────┐
        页面加载 →│   idle   │←──────────────┐
                  └────┬─────┘                │
                       │                      │
          ┌────────────┼────────────┐         │
          ▼            ▼            ▼         │
    ┌──────────┐ ┌──────────┐ ┌──────────┐   │
    │ working  │ │  paused  │ │  closed  │   │
    └────┬─────┘ └──────────┘ └──────────┘   │
         │                                    │
    ┌────┴────┐                               │
    ▼         ▼                               │
┌───────┐ ┌───────┐                           │
│ buy   │ │ sell  │──── 动画结束 ─────────────┘
│ anim  │ │ anim  │
└──┬────┘ └──┬────┘
   │         │
   ▼         ▼
 粒子特效  粒子特效
 (红色)    (绿色)
```

#### 各状态详解

| 状态 | 触发条件 | 机甲行为 | 持续时间 |
|------|----------|----------|----------|
| `idle` | 页面初次加载 | 站立待命，核心慢速脉冲，面罩扫描线往返，关节微浮动 | 循环 |
| `working` | 市场开盘期间 | 机械臂高速操作全息台，头部扫描三屏，推进器待机闪烁，散热口间歇排气 | 循环（随机切换子动画）|
| `paused` | 模拟账户暂停 | 机甲冻结当前帧，表面覆盖灰色能量护盾，核心熄暗 | 持续直到恢复 |
| `closed` | 市场休市 | 机甲进入休眠舱姿态：头部垂下、核心调暗、推进器收纳、面罩显示"Zzz"像素字 | 持续直到开盘 |
| `auto_trading` | 自动交易运行中 | 超频模式：核心狂脉冲（赤金色）、双臂残影操作、推进器预热喷蓝焰、面罩显示"OVERDRIVE"、全身电弧特效 | 循环 |
| `buy_anim` | 买入委托提交 | 机甲核心熔炉超载红炽 → 双臂上举蓄能 → 背部推进器全开喷射赤焰 → 全息屏全红闪 → 粒子散射 | 1.5s |
| `sell_anim` | 卖出委托提交 | 机甲核心冷静脉动 → 右臂前伸食指确认键 → 散热阀全开排出绿焰 → 全息屏绿闪 → 粒子沉降 | 1.5s |

### 2.3 粒子特效（机甲专属）

买入和卖出分别触发不同的机甲能量释放特效：

**买入粒子 — 核心熔炉超载（Core Overload）**
- 能量流颜色：#c62828 → #e53935 → #ff8a80 → #ffcdd2（赤焰渐变）
- 粒子形状：爆炸碎片（3×3 px 方块 + 4×1 px 横条模拟火花）
- 发射源：机甲核心熔炉 + 背部双推进器（三个发射点）
- 运动轨迹：核心粒子球状扩散（8 方向蛇形路径），推进器粒子向后上方扇形喷射
- 粒子上限：80 个（核心 40 + 推进器各 20），生命周期 1.2s
- 全息屏闪红：三面屏幕填充 #c62828 alpha 闪 3 次（0.15s 间隔）
- 配套文字："BUY {symbol}" 以 5×7 像素矩阵字体，从核心位置弹出后上浮消散

**卖出粒子 — 散热阀冷却排放（Coolant Vent）**
- 能量流颜色：#1f8b4c → #43a047 → #a5d6a7 → #c8e6c9（冷焰渐变）
- 粒子形状：液滴碎片（2×3 px 竖条 + 2×2 px 方块模拟冷却液）
- 发射源：膝部两侧排气口 + 肩甲散热槽（四个发射点）
- 运动轨迹：向下飘落带水平漂移扩散，落地溅起次级粒子（3-4 个 1×1 px 迷你点）
- 粒子上限：60 个（主粒子 40 + 溅射 20），生命周期 1.0s
- 全息屏闪绿：三面屏幕填充 #1f8b4c alpha 闪 2 次（0.2s 间隔）
- 配套文字："SELL {symbol}" 以 5×7 像素矩阵字体，从面罩位置弹出后右移消散

**弹药补充 — 通用逻辑**
- 粒子生命期内 alpha 从 1.0 线性衰减到 0
- 粒子大小随生命衰减（scale 1.0 → 0.2）
- 买入粒子带 0.5-1.5 px/frame 随机初速，卖出粒子带 0.3-1.0 px/frame
- 粒子碰撞检测：与画布边缘碰撞后反弹一次，能量衰减 50%

## 4. 动画系统实现

### 4.1 Canvas 渲染管线

```
requestAnimationFrame
  │
  ├── 1. 计算 deltaTime (距上一帧的毫秒数)
  │
  ├── 2. 状态机更新
  │     ├── 检查 lastOrderAction.timestamp
  │     ├── 判断是否触发 buy/sell 动画
  │     └── 更新当前状态和子动画计时器
  │
  ├── 3. 清除画布
  │
  ├── 4. 绘制背景（机甲指挥舱场景）
  │     ├── 舱壁金属网格底板
  │     ├── 操作台（环抱式弧形台面）
  │     └── 三面全息投影屏（静态框 + 屏内动态数据）
  │
  ├── 5. 绘制机甲精灵（当前帧）
  │     ├── 腿部 / 髋甲
  │     ├── 核心熔炉（脉冲发光，独立 alpha 通道）
  │     ├── 躯干装甲 + 肩甲
  │     ├── 机械臂（关节角度参数化）
  │     ├── 头部 + 面罩（扫描线动画）
  │     ├── 推进器（展开/收纳/喷射状态）
  │     └── 电弧特效叠加层（auto_trading 状态）
  │
  ├── 6. 绘制粒子特效层
  │     ├── 更新粒子位置、速度、透明度
  │     ├── 移除死亡粒子
  │     └── 绘制存活粒子
  │
  ├── 7. 绘制 UI 叠加层（可选）
  │     └── 动作提示文字
  │
  └── 8. requestAnimationFrame(loop)
```

### 4.2 关键实现细节

**机甲绘制方式**
- 不使用外部 sprite sheet，全部用 Canvas 2D API 程序化绘制
- 机甲由约 70-90 个矩形 + 少量三角形（肩甲尖角）拼成，分 9 层绘制
- 绘制顺序（后→前）：背景舱壁 → 推进器 → 全息屏 → 腿部 → 髋甲 → 躯干 → 核心 → 肩甲 → 机械臂 → 头部 → 面罩 → 叠加特效
- 每个状态对应一组关节角度参数（肩角、肘角、头倾角、推进器开度），参数平滑插值过渡

**全息屏内容动画**
- 左侧全息屏：K 线柱状滚动（2px 宽的竖条，红绿随机，逐帧上移）
- 中间全息屏：数据矩阵闪烁（4×3 像素数字 0-9 快速替换）
- 右侧全息屏：雷达扫描线（对角线往复）+ 目标点闪烁

**核心熔炉呼吸光**
- 三层嵌套矩形：外层暗金环（固定）、中层光晕（alpha 正弦波 0.3-0.8）、内层白热芯（alpha 正弦波 0.6-1.0）
- 呼吸周期：idle 3.0s，working 1.5s，auto_trading 0.4s

**面罩扫描线**
- 一条 1px 高的蓝色横线（#3b82f6）在面罩区域内上下往复
- 速度：idle/working 0.5 px/frame，auto_trading 2 px/frame
- 扫描线到达底部时触发面罩全闪（持续 2 帧）

**帧率控制**
- 角色动画：12 fps（像素风格帧动画）
- 粒子特效：60 fps（平滑粒子运动）
- 屏幕闪烁：8 fps（数据更新感）

**性能**
- Canvas 尺寸 256×256，每帧绘制约 200 个矩形 + 60 个粒子
- 预估每帧耗时 < 1ms（无外部资源加载）
- 空闲时降低帧率到 6 fps 节省资源

## 5. 委托录入弹窗（OrderModal）

保留委托录入功能，改为紧凑弹窗形式。

### 5.1 触发方式

- 点击角色身体区域
- 点击面板标题栏的 [+委托] 按钮
- 快捷键（可选）：Ctrl/Cmd + N

### 5.2 弹窗设计

```

│  录入模拟委托                    ✕  │
├─────────────────────────────────────┤
```

- 锁定状态（自动交易中）时按钮禁用

## 8. 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| Canvas 不支持 | 降级显示静态 PNG placeholder + 文字提示 |
| 市场状态未知 | 默认 idle 状态 |
| 快速连续提交委托 | 动画队列：上一个动画结束后播放下一个（最长队列 3 个） |
| 页面不可见（切换标签页） | `document.hidden` 检测，暂停 requestAnimationFrame |
| 自动交易运行中提交委托 | 角色短暂切换到 auto_trading 状态，弹窗表单锁定 |
| 账户暂停 | 角色冻结 + 灰度滤镜，弹窗表单锁定 |
| 无任何成交记录 | 状态栏显示"等待首个委托" |

### 10.2 帧动画参数表（关键帧定义）

| 帧 ID | 头部 Y 偏移 | 左臂角度 | 右臂角度 | 核心 alpha | 推进器开度 | 面罩扫描 Y | 用途 |

| `stand_01` | -1 | 18° | -12° | 0.7 | 0% | 10 | idle 呼吸帧 |
| `work_00` | 0 | 45° | -30° | 0.7 | 10% | 12 | working 操作台 |
| `work_01` | 0 | 60° | -45° | 0.8 | 10% | 14 | working 伸展 |
| `work_02` | -1 | 30° | -20° | 0.6 | 5% | 6 | working 切换屏 |
| `buy_00` | -3 | 120° | -120° | 1.0 | 100% | 18 | buy 蓄能顶帧 |
| `buy_01` | -5 | 135° | -135° | 1.0 | 100% | 20 | buy 爆发帧 |
| `sell_00` | 0 | 80° | 20° | 0.3 | 0% (散热全开) | 6 | sell 确认帧 |
| `sleep_00` | 0 | -10° | 10° | 0.15 | 0% | 0 (熄灭) | closed 休眠帧 |

### 10.3 实际实现方式

使用 Canvas `fillRect(x, y, w, h)` 逐矩形绘制，不同部位使用不同色块。每个帧定义为一个绘制函数数组，按层序调用。关键帧之间通过参数线性插值生成过渡帧。

## 11. 开放问题

1. **音频效果**：是否在买入/卖出时添加 8-bit 机甲音效（核心充能嗡鸣 / 散热排气声 / 推进器点火）？
2. **机甲换装**：是否需要多套机甲皮肤（沙漠涂装 / 极地涂装 / 暗夜涂装），在设置页切换？
3. **可配置性**：是否需要在设置页控制机甲显示/隐藏，或调节画布缩放倍率？
4. **机甲升级**：未来是否需要战绩积累 → 解锁新配件（肩炮 / 能量盾 / 浮游炮）等游戏化元素？
5. **移动端适配**：小屏幕下机甲尺寸是否需要缩小到 1.5x 渲染，或裁剪为半身像？
6. **全息屏风格**：指挥舱背景是否需要日间/夜间模式（亮舱 / 暗舱）切换？

这些问题可以留待 v2 迭代时讨论。
