# 尾盘强势承接，次日冲高卖策略方案

更新时间：2026-04-30

## 1. 策略定位

本策略做的是尾盘资金提前回流后的隔日惯性冲高。

- 策略类型：尾盘承接 + 隔日冲高兑现
- 持股周期：1 个交易日为主，最多 2 个交易日
- 收益目标：1.5%-3.5%
- 风格目标：胜率优先，小盈利快兑现

核心原则：

> 尾盘买承接，次日卖预期。

本策略不是追涨，也不是趋势持仓策略。买入后只等待次日冲高，没有冲高就降级退出。

## 2. 适用环境

### 2.1 适合环境

| 市场状态 | 操作 |
|---|---|
| 指数震荡但不破位 | 可做 |
| 情绪修复日 | 可做 |
| 主线板块尾盘回流 | 优先 |
| 缩量震荡 | 小仓做 |
| 指数全天弱但尾盘修复 | 谨慎做 |

### 2.2 禁止环境

| 环境 | 原因 |
|---|---|
| 跌停数明显增加 | 次日低开风险大 |
| 炸板率超过 45% | 短线接力失败率高 |
| 高位股批量跌停 | 情绪退潮 |
| 指数尾盘跳水 | 隔日预期差 |
| 外围或政策有重大不确定性 | 隔夜风险不可控 |

### 2.3 市场参数

| 指标 | 建议阈值 |
|---|---:|
| 上涨家数占比 | >= 40% |
| 涨停数 | >= 30 |
| 跌停数 | <= 10 |
| 炸板率 | <= 40% |
| 指数尾盘 30 分钟 | 不继续走弱 |
| 主线板块 | 至少 1 个板块尾盘回流 |

## 3. 选股条件

### 3.1 个股基础条件

| 条件 | 建议 |
|---|---:|
| 成交额 | >= 2 亿 |
| 流通市值 | 30-500 亿优先 |
| 当日涨跌幅 | -1% 到 +6% |
| 当日振幅 | 3%-9% |
| 换手率 | 3%-18% |
| 价格位置 | 不处于连续大涨后的极端高位 |
| 风险 | 无跌停、无严重长上影、无放量破位 |

### 3.2 强势承接条件

至少满足 4 条：

| 条件 | 说明 |
|---|---|
| 收盘价站上 VWAP | 表示全天均价上方有承接 |
| 14:30 后不破 VWAP | 尾盘资金没有放弃 |
| 尾盘低点抬高 | 分时结构转强 |
| 收盘在日内振幅上半区 | 收盘位置强 |
| 尾盘成交温和放大 | 有资金回流，不是缩量假拉 |
| 个股强于板块 | 个股有主动性 |
| 板块尾盘同步回流 | 不是孤立拉升 |

### 3.3 排除条件

以下任一出现，放弃：

- 尾盘 10 分钟直线拉升超过 4%，且没有回踩确认。
- 收盘前明显放量砸盘。
- 全天长上影，收盘弱于 VWAP。
- 板块尾盘走弱，个股逆势硬拉。
- 个股存在公告、减持、监管、业绩雷风险。
- 当天已经连续大涨 2-3 天，尾盘再拉高。

## 4. 买点设计

### 4.1 标准买点

| 维度 | 条件 |
|---|---|
| 时间 | 14:30-14:55 |
| 价格 | 回踩 VWAP 不破后重新上拐 |
| 结构 | 尾盘回踩日内均价线或分时平台不破 |
| 确认 | 收盘前确认不跳水 |

买入方式：

| 买点 | 仓位 |
|---|---:|
| 回踩 VWAP 不破 | 8%-10% |
| 尾盘二次抬高 | 6%-8% |
| 收盘前确认强势 | 5%-6% |

### 4.2 不追规则

不买：

- 14:50 后突然直线拉升。
- 尾盘涨幅超过 7%。
- 离 VWAP 超过 3.5%。
- 当天已经冲高回落过一次，尾盘再拉。
- 板块没有配合。

## 5. 次日卖出规则

### 5.1 标准止盈

| 次日表现 | 操作 |
|---|---|
| 高开 1%-3% | 开盘后观察 5-15 分钟，冲高卖 |
| 平开后快速上冲 | +1.5%-3% 分批卖 |
| 低开后翻红 | 翻红后冲高减仓 |
| 冲高 3% | 至少卖出 50% |
| 冲高 5% | 大部分卖出 |
| 涨停 | 看封单，可保留少量 |

### 5.2 失败处理

| 次日表现 | 操作 |
|---|---|
| 低开超过 -3% | 不补仓，等反抽减亏 |
| 开盘 30 分钟不站 VWAP | 降级退出 |
| 跌破前一日尾盘承接位 | 退出 |
| 板块低开低走 | 提前退出 |
| 高开低走跌破开盘价 | 退出 |

### 5.3 时间止损

| 时间 | 规则 |
|---|---|
| 9:45 前 | 没有冲高且弱于板块，减仓 |
| 10:30 前 | 仍未站稳 VWAP，退出 |
| T+1 收盘 | 原则上不留，除非涨停或极强 |
| T+2 | 最晚清仓 |

## 6. 参数建议

| 参数 | 建议值 |
|---|---:|
| 买入时间 | 14:30-14:55 |
| 收盘位置 | 日内振幅上半区，最好 >= 60% |
| 距 VWAP | 0%-3% |
| 尾盘涨幅 | 不超过 6%-7% |
| 第一止盈 | +1.5% |
| 标准止盈 | +3% |
| 强止盈 | +5% |
| 止损 | -2.5% 到 -3.5% |
| 最大持有 | 2 个交易日 |
| 单票仓位 | 5%-10% |

## 7. 评分模型

| 因子 | 分数 |
|---|---:|
| 市场环境 | 0-15 |
| 板块尾盘回流 | 0-20 |
| 个股收盘位置 | 0-15 |
| VWAP 承接 | 0-20 |
| 尾盘量能健康 | 0-10 |
| 个股强于板块 | 0-10 |
| 风险扣分 | -30 到 0 |

信号分层：

| 分数 | 动作 |
|---|---|
| >= 85 | 可小仓执行 |
| 75-85 | 观察，尾盘确认后执行 |
| 60-75 | 只观察 |
| < 60 | 放弃 |

## 8. 回测口径

必须统计：

- T 日 14:30 后入场价
- T+1 开盘收益
- T+1 最高收益
- T+1 10:30 前最高收益
- T+1 收盘收益
- T+1 是否触发 +1.5%、+3%、+5%
- T+1 最大回撤
- T+2 收盘收益
- 板块是否同步回流
- 是否尾盘直线拉升

核心门槛：

| 指标 | 目标 |
|---|---:|
| T+1 冲高 1.5% 命中率 | >= 65% |
| T+1 冲高 3% 命中率 | >= 50% |
| 平均净收益 | >= 0.35% |
| 净胜率 | >= 55% |
| 止损率 | <= 12% |
| 最大持有 | <= 2 天 |

## 10. 执行摘要

本策略只做尾盘承接，不做尾盘偷袭拉升。次日有冲高就兑现，没有冲高就走。核心是控制隔夜风险，目标是高胜率的小利润。
