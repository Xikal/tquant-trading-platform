# 板块主线首分歧低吸策略方案

更新时间：2026-04-30

## 1. 策略定位

板块主线首分歧低吸不是“跌了就买”，而是在市场已经确认某个板块为主线之后，第一次出现分歧释放时，只低吸板块核心前排，博弈资金回流和主线延续。

- 策略类型：情绪周期 + 板块强度 + 核心股低吸
- 适用周期：1-3 个交易日
- 核心收益来源：主线第一次分歧后的资金回流、核心股换手后的反包、板块继续发酵时的前排溢价

不做：

- 非主线板块
- 后排杂毛
- 高潮日追涨
- 主线退潮日抄底
- 连续分歧第二天、第三天盲目低吸

## 2. 策略逻辑

A 股短线资金通常有明显的主线抱团特征。一个板块成为主线后，常见节奏如下：

1. 启动日：板块突然爆发，出现多只首板。
2. 确认日：龙头继续晋级，板块扩散。
3. 高潮日：板块大面积上涨，后排补涨。
4. 首分歧日：龙头开板、后排掉队、板块分化。
5. 修复日：资金回流前排，龙头或强跟随反包。

本策略只做第 4 步和第 5 步之间的机会。

核心假设：

> 第一次分歧通常是换手，不一定是退潮。如果主线没有被证伪，分歧后资金会优先回流核心前排。

## 3. 策略适用环境

### 3.1 允许交易的市场环境

| 市场状态 | 是否允许 |
|---|---|
| 指数稳定，题材活跃 | 允许 |
| 指数震荡，主线明确 | 允许 |
| 缩量轮动，但主线强 | 小仓允许 |
| 高位退潮 | 禁止 |
| 跌停潮 / 风险释放 | 禁止 |
| 板块快速一日游 | 禁止 |

### 3.2 市场过滤条件

建议满足至少 3 条：

| 指标 | 建议阈值 |
|---|---:|
| 全市场涨停数 | >= 40 |
| 跌停数 | <= 10 |
| 炸板率 | <= 35% |
| 连板高度 | >= 3 板 |
| 上涨家数占比 | >= 45% |
| 主线板块涨停数 | >= 3 |
| 主线板块成交额 | 较 5 日均值放大 >= 1.3 倍 |

如果市场处于明显退潮，比如跌停数大增、炸板率超过 45%、高位股批量跌停，本策略暂停。

## 4. 主线板块识别

不是涨得多就是主线。主线必须同时具备强度、持续性、扩散性和辨识度。

### 4.1 主线确认条件

| 维度 | 条件 |
|---|---|
| 涨幅 | 最近 2-3 日板块涨幅市场前 5 |
| 涨停 | 板块内至少 3 只涨停 |
| 成交 | 板块成交额较 5 日均值放大 1.3 倍以上 |
| 持续 | 至少连续 2 日有资金回流 |
| 梯队 | 有龙头、强跟随、中军或补涨梯队 |
| 题材 | 有明确催化，非纯随机异动 |

### 4.2 主线强度评分

| 因子 | 分值 |
|---|---:|
| 板块涨幅排名前 3 | 15 |
| 板块涨停数 >= 5 | 15 |
| 板块成交额放大 >= 1.5 倍 | 15 |
| 龙头晋级或反包 | 20 |
| 板块内有中军放量趋势 | 10 |
| 板块连续性 >= 2 日 | 15 |
| 板块强于指数 >= 2% | 10 |

评分分层：

| 分数 | 状态 |
|---|---|
| >= 80 | 强主线 |
| 65-80 | 次主线 |
| 50-65 | 观察 |
| < 50 | 不参与 |

本策略只做强主线和少量次主线。

## 5. 首分歧定义

首分歧不是板块随便跌一天，而是：

> 板块已经连续走强后，第一次出现明显分化，但核心龙头没有被彻底证伪。

### 5.1 首分歧量化条件

建议满足以下条件中的多数：

| 指标 | 条件 |
|---|---|
| 板块涨停数 | 较前一日减少 |
| 炸板率 | 明显上升，但不超过 45% |
| 龙头 | 开板、放量、长上影或断板 |
| 后排 | 补涨股明显掉队 |
| 板块指数 | 高开低走或冲高回落 |
| 成交量 | 板块放量，说明有换手 |
| 跌停 | 板块核心不能出现批量跌停 |

### 5.2 首分歧与退潮的区别

| 情况 | 首分歧 | 退潮 |
|---|---|---|
| 龙头 | 开板但承接强 | 跌停或大阴破位 |
| 板块 | 分化但仍有活口 | 集体杀跌 |
| 后排 | 掉队 | 批量核按钮 |
| 资金 | 前排换手 | 全面撤退 |
| 次日预期 | 有修复可能 | 继续补跌风险大 |

如果无法区分首分歧和退潮，宁愿不做。

## 6. 个股选择

只做三类票：

| 类型 | 说明 | 优先级 |
|---|---|---|
| 龙头 | 板块最高辨识度、空间核心 | 最高 |
| 强跟随 | 跟随龙头最紧，走势强于板块 | 高 |
| 容量中军 | 成交额大、趋势稳定、大资金参与 | 中高 |

不做：

- 后排补涨
- 无辨识度首板
- 一字板开板后承接弱
- 连续缩量加速后首次爆量派发
- 板块内排名靠后的套利票

个股筛选条件：

| 条件 | 建议 |
|---|---|
| 成交额 | >= 2 亿，容量票 >= 5 亿 |
| 板块地位 | 龙头 / 强跟随 / 中军 |
| 距离 5 日线 | 不宜偏离过大 |
| 分歧跌幅 | -1% 到 -6% 优先 |
| 换手 | 放量但不能天量派发 |
| 承接 | 不破关键均线或分时 VWAP 能收回 |
| 风险 | 无减持、监管、业绩雷、极端高位见顶迹象 |

## 7. 买点设计

本策略有两个买点：分歧尾盘低吸和次日弱转强确认。

### 7.1 买点 A：分歧尾盘低吸

适合更成熟的交易者，要求更严格。

| 条件 | 要求 |
|---|---|
| 时间 | 14:30 后更优 |
| 板块 | 分歧但没有崩盘 |
| 龙头 | 未跌停，尾盘有资金回流 |
| 个股 | 回踩关键位不破 |
| 分时 | 跌不动，低点抬高 |
| 成交 | 恐慌释放后缩量企稳 |
| 仓位 | 轻仓试错 |

优点：位置低，盈亏比好。  
风险：如果次日继续退潮，会低开亏损。

### 7.2 买点 B：次日弱转强确认

这是更推荐系统化的买点。

| 条件 | 要求 |
|---|---|
| 竞价 | 不弱于板块，不低于预期 |
| 开盘 | 低开能快速翻红，或小高开不兑现 |
| 分时 | 站上 VWAP |
| 回踩 | 回踩 VWAP 不破 |
| 强度 | 强于板块平均 |
| 龙头 | 龙头同步修复或继续走强 |
| 价格 | 不追高超过 5% |

买点优先级：

1. 低开后快速翻红，回踩 VWAP 不破。
2. 平开震荡后放量突破早盘高点。
3. 龙头反包带动强跟随同步走强。
4. 板块指数由弱转强，核心股率先修复。

不允许：

- 高开 7% 以上追
- 一根直线拉升后追
- 龙头走弱时买后排
- 板块没有回流，只买个股形态

## 8. 卖出与风控

### 8.1 止损规则

| 情况 | 动作 |
|---|---|
| 跌破分歧日低点 | 退出 |
| 跌破 VWAP 后无法收回 | 退出 |
| 龙头跌停或大幅走弱 | 退出 |
| 板块回流失败 | 退出 |
| 买入后次日无溢价 | 降级退出 |

### 8.2 止盈规则

| 盈利状态 | 动作 |
|---|---|
| 冲高 3% | 减仓 30%-50% |
| 冲高 5% | 减仓 50%-70% |
| 反包涨停 | 可保留部分观察封单 |
| 冲高回落跌破 VWAP | 剩余仓位退出 |
| 次日不能继续强 | 不恋战 |

### 8.3 时间止损

| 时间 | 规则 |
|---|---|
| 买入当日 | 必须收在 VWAP 上方或强于板块 |
| T+1 | 没有冲高或修复，退出 |
| T+2 | 仍不能走强，全部退出 |

这不是中线策略，不能把失败的首分歧低吸变成长期持仓。

## 9. 仓位规则

| 信号质量 | 仓位 |
|---|---:|
| 分歧尾盘试错 | 5%-8% |
| 次日弱转强确认 | 8%-12% |
| 龙头强反包 | 10%-15% |
| 市场缩量轮动 | 不超过 8% |
| 板块次主线 | 不超过 6% |
| 退潮或风险释放 | 0% |

单日最多做 1-2 只，不要同板块买一堆，因为风险高度相关。

## 10. 参数建议

| 参数 | 建议值 |
|---|---:|
| 板块连续强势天数 | 2-4 日 |
| 首分歧出现时间 | 主线确认后第 2-5 日 |
| 板块涨停数 | >= 3 |
| 板块成交放大 | >= 1.3 倍 |
| 个股成交额 | >= 2 亿 |
| 个股跌幅 | -1% 到 -6% 优先 |
| 高开追买上限 | <= 5% |
| 炸板率警戒线 | 35% |
| 炸板率禁入线 | 45% |
| 跌停数警戒线 | 10-15 只 |
| 第一止盈 | +3% |
| 第二止盈 | +5% |
| 最大持有 | 3 个交易日 |

## 11. 策略评分模型

### 11.1 板块分

| 因子 | 分数 |
|---|---:|
| 板块涨幅排名 | 0-15 |
| 涨停数量 | 0-15 |
| 成交额放大 | 0-15 |
| 梯队完整度 | 0-15 |
| 龙头强度 | 0-20 |
| 持续性 | 0-10 |
| 指数环境 | 0-10 |

### 11.2 个股分

| 因子 | 分数 |
|---|---:|
| 龙头地位 | 0-25 |
| 分时承接 | 0-20 |
| 量价健康 | 0-15 |
| 距离关键支撑 | 0-15 |
| 弱转强确认 | 0-15 |
| 风险扣分 | -30 到 0 |

### 11.3 信号分层

| 总分 | 状态 |
|---|---|
| >= 85 | 可小仓确认 |
| 75-85 | 接近买点 |
| 60-75 | 观察 |
| < 60 | 放弃 |

## 12. 回测方案

每个样本必须记录：

- 主线板块名称
- 主线确认日
- 首分歧日
- 分歧日板块涨停数、炸板率、成交额
- 龙头表现
- 候选个股地位
- 买点类型：尾盘低吸 / 次日弱转强
- 入场价
- T+1、T+2、T+3 收益
- 最大冲高
- 最大回撤
- 是否触发止损
- 是否板块退潮

核心评估指标：

| 指标 | 目标 |
|---|---:|
| 成交样本 | >= 300 |
| 净胜率 | >= 52% |
| 平均净收益 | >= 0.60% |
| 冲高 3% 命中率 | >= 62% |
| 止损率 | <= 12% |
| Profit Factor | >= 1.40 |
| 最大连续亏损 | <= 5 笔 |
| 退潮日误触发率 | 越低越好 |

必须分桶：

- 龙头 / 强跟随 / 中军 / 后排
- 分歧尾盘买 / 次日确认买
- 强主线 / 次主线
- 市场修复 / 震荡 / 退潮
- 高开 / 平开 / 低开
- 是否站上 VWAP
- 龙头是否反包
- 板块是否二次回流

如果后排样本收益显著差，后排直接永久排除。

## 13. 风险清单

| 风险 | 处理 |
|---|---|
| 首分歧误判为退潮 | 加龙头状态和跌停数过滤 |
| 后排补跌 | 只做前排 |
| 分歧日低吸太早 | 优先尾盘或次日确认 |
| 板块一日游 | 要求连续性和梯队 |
| 高开追涨被砸 | 高开超过 5% 不追 |
| 龙头爆量见顶 | 天量长上影降级 |
| 市场系统性风险 | 跌停潮、风险释放期禁入 |

## 14. 最终执行模板

1. 判断市场是否允许交易。
2. 找最近 2-3 日最强板块。
3. 判断该板块是否已经成为主线。
4. 识别是否出现第一次分歧。
5. 只筛选板块龙头、强跟随、中军。
6. 分歧尾盘只允许轻仓试错。
7. 次日弱转强确认才提高确定性。
8. 冲高 3%-5% 主动止盈。
9. T+2 仍不强，退出。
10. 板块退潮，全部放弃。

一句话总结：

> 板块主线首分歧低吸，买的不是“下跌”，而是“主线第一次换手后的资金回流”。核心是主线、前排、首次分歧、弱转强确认，四个条件缺一不可。
