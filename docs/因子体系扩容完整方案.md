## 零、现有因子体系架构

### 当前数据流

```
BoardCandidate + history DataFrame
    → CandidateMetrics (79 字段，纯日线)
        → _factor_scores(metrics) → {"deep_pullback_factor": 3.5, "trend_rebound_factor": 2.0}
            → factor_bonus = min(5.0, sum) 加到 adjusted_score
            → dynamic_adjustments.factor_bonuses 用于 floor_shift 和 position_multiplier
```

### 当前限制

1. **单候选盲区**：`_factor_scores(metrics)` 只接受单个 `CandidateMetrics`，无法感知板块内其他候选股
2. **日线局限**：没有日内分时数据，无法做承接质量评估
3. **无外部数据**：不使用 akshare 资金流向等外部数据源
4. **无历史上下文**：无法访问 `history` DataFrame，只能使用 `CandidateMetrics` 中已计算好的聚合指标

### [F-01] 缩量质量因子 (shrink_quality_factor)

**价值**：把当前二值的 `shrink_ok` / `shrink_basic_ok` 升级为连续打分。缩量的"形态"比"是否缩到某个阈值"更重要。

**数据来源**：`post_board` DataFrame（`history.iloc[board_index+1 : latest_index+1]`）

**文件**：`backend/app/services/low_buy/signal_family.py`

```python
def evaluate_shrink_quality_factor(metrics: CandidateMetrics) -> float:
    """
    缩量质量因子：从缩量形态（而不仅是缩量幅度）评估回撤健康度。
    
    评分逻辑：
    1. 缩量均匀性（0-3）：连续缩量（shrink_staircase）+2.5，跳量（先缩后放）+1.0
    2. 缩量速度（0-2）：量能下降斜率，从启动日到最近日的均量递减率
    3. 异常放量惩罚（0- -2）：回撤期间是否有放量日（超过启动日的 80%）
    4. 缩量价格效率（0-3）：量缩得比价快 → 主动性卖盘在衰减
    """
    score = 0.0
    
    # 1. 缩量阶梯
    if metrics.shrink_staircase:
        score += 2.5
    elif metrics.shrink_quality_score >= 5.0:  # 来自 metrics 的连续打分
        score += 1.5
    elif metrics.shrink_basic_ok:
        score += 0.8
    
    # 2. 缩量速度（post_volume_ratio 越低越好）
    if metrics.post_volume_ratio <= 0.55:
        score += 2.0
    elif metrics.post_volume_ratio <= 0.72:
        score += 1.5
    elif metrics.post_volume_ratio <= 0.88:
        score += 0.8
    
    # 3. 异常放量天数惩罚
    if metrics.abnormal_volume_days >= 3:
        score -= 2.0
    elif metrics.abnormal_volume_days >= 1:
        score -= 1.0
    
    # 4. 缩量波动率（shrink_volatility 低 = 稳定缩量）
    if metrics.shrink_volatility <= 0.15:
        score += 3.0
    elif metrics.shrink_volatility <= 0.30:
        score += 1.5
    
    return round(_clamp(score, 0.0, 5.0), 2)
```

```python
def _compute_shrink_quality(volumes: list[float]) -> float:
    """评估量能下降的线性度。0-10 分，越高越线性。"""
    if len(volumes) < 3:
        return 5.0
    # 线性回归残差：理想缩量是一条下降线
    n = len(volumes)
    x_mean = (n - 1) / 2.0
    y_mean = sum(volumes) / n
    numerator = sum((i - x_mean) * (volumes[i] - y_mean) for i in range(n))
    denominator = sum((i - x_mean) ** 2 for i in range(n))
    if denominator == 0:
        return 5.0
    slope = numerator / denominator
    intercept = y_mean - slope * x_mean
    residuals = sum((volumes[i] - (slope * i + intercept)) ** 2 for i in range(n))
    rmse = (residuals / n) ** 0.5
    # 归一化到 0-10（RMSE 越低越好）
    normalized = max(0.0, 10.0 - rmse / max(y_mean, 1.0) * 10.0)
    return round(min(10.0, normalized), 2)
```

### [F-02] 波动率区间因子 (volatility_regime_factor)

**价值**：判断回撤期间多空双方是"在收敛（快出方向）"还是"在发散（还在博弈）"。

**数据来源**：`post_board` 中每日 `high` / `low`

**文件**：`backend/app/services/low_buy/signal_family.py`

```python
def evaluate_volatility_regime_factor(metrics: CandidateMetrics) -> float:
    """
    波动率区间因子：回撤期振幅是在收敛还是发散。
    
    收敛 = 多空在当前位置达成共识，容易出方向（加分）
    发散 = 多空还在激烈博弈，此时进场属于赌方向（扣分）
    """
    score = 0.0
    
    # ATR 趋势（负值 = 收敛，正值 = 发散）
    if metrics.retracement_atr_trend <= -0.15:
        score += 3.0  # 明显收敛
    elif metrics.retracement_atr_trend <= -0.05:
        score += 1.5  # 轻微收敛
    elif metrics.retracement_atr_trend >= 0.15:
        score -= 1.5  # 明显发散
    
    # ATR 绝对值（相对收盘价）
    atr_pct = metrics.retracement_atr / max(metrics.latest_close, 0.01) * 100
    if 1.5 <= atr_pct <= 4.0:
        score += 1.5  # 适度波动（有操作空间）
    elif atr_pct > 7.0:
        score -= 1.0  # 波动太大（止损容易被扫）
    
    return round(_clamp(score, 0.0, 5.0), 2)
```

**metrics 计算**（在 `candidate_metrics.py` 中新增函数）：

```python
def _compute_retracement_volatility(post_board: pd.DataFrame) -> dict:
    """计算回撤期波动率特征。"""
    if len(post_board) < 3:
        return {"retracement_atr": 0.0, "retracement_atr_trend": 0.0}
    
    # ATR 简化版：每日振幅
    daily_ranges = [
        float(row["high"]) - float(row["low"])
        for _, row in post_board.iterrows()
    ]
    avg_range = sum(daily_ranges) / len(daily_ranges)
    
    # ATR 趋势：前半段 vs 后半段
    mid = len(daily_ranges) // 2
    first_half_avg = sum(daily_ranges[:mid]) / max(mid, 1)
    second_half_avg = sum(daily_ranges[mid:]) / max(len(daily_ranges) - mid, 1)
    atr_trend = (second_half_avg - first_half_avg) / max(first_half_avg, 0.01)
    
    return {
        "retracement_atr": round(avg_range, 3),
        "retracement_atr_trend": round(atr_trend, 4),
    }
```

### [F-03] 跳空风险因子 (gap_risk_factor)

**价值**：T+1 制度下最重要的风险维度。跳空缺口 = 无成交区间 = 全是套牢盘。股价反弹到缺口附近时解套盘集中涌出。

**数据来源**：`post_board` 中每日 `open` vs 前日 `low`/`high`

**文件**：`backend/app/services/low_buy/signal_family.py`

```python
def evaluate_gap_risk_factor(metrics: CandidateMetrics) -> float:
    """
    跳空风险因子：检测回撤期间的未回补跳空缺口。
    
    向下跳空 = 开盘价 < 前日最低价 → 缺口下沿以上全是套牢盘
    回补 = 后续价格回到跳空前的最低点以上
    
    因子值越高 = 风险越低（即缺口少/小/已回补）
    """
    score = 5.0  # 起始满分，扣分制
    
    # 每个未回补缺口扣分
    if metrics.unfilled_gap_count >= 3:
        score -= 3.0
    elif metrics.unfilled_gap_count >= 1:
        score -= metrics.unfilled_gap_count * 1.0
    
    # 最大缺口幅度
    if metrics.max_gap_size_pct >= 3.0:
        score -= 2.0
    elif metrics.max_gap_size_pct >= 1.5:
        score -= 1.0
    
    # 最近缺口距离（越近越危险——可能还在缺口下方）
    if metrics.latest_gap_distance_pct <= 2.0:
        score -= 1.5
    
    # 如果当前价格已经在缺口上沿上方 → 加分（缺口已被突破）
    if metrics.latest_gap_distance_pct >= 5.0 and metrics.unfilled_gap_count > 0:
        score += 1.0  # 已脱离缺口区域
    
    return round(_clamp(score, 0.0, 5.0), 2)
```

**metrics 计算**（在 `candidate_metrics.py` 中新增函数）：

```python
def _compute_gap_risk(
    post_board: pd.DataFrame,
    latest_close: float,
) -> dict:
    """检测回撤期间未回补的跳空缺口。"""
    unfilled_gaps = []
    max_gap_size = 0.0
    latest_gap_distance = 99.0
    
    rows = list(post_board.iterrows())
    for i in range(1, len(rows)):
        prev_idx, prev_row = rows[i - 1]
        curr_idx, curr_row = rows[i]
        prev_low = float(prev_row["low"])
        prev_high = float(prev_row["high"])
        curr_open = float(curr_row["open"])
        
        # 向下跳空：今日开盘 < 昨日最低
        if curr_open < prev_low:
            gap_size_pct = (prev_low - curr_open) / max(prev_low, 0.01) * 100
            # 检查是否已回补：后续最高价是否回到跳空前低点以上
            subsequent_highs = [
                float(post_board.iloc[j]["high"])
                for j in range(i, len(post_board))
            ]
            gap_filled = any(h >= prev_low for h in subsequent_highs)
            if not gap_filled:
                unfilled_gaps.append({
                    "gap_size_pct": gap_size_pct,
                    "gap_top": prev_low,
                    "gap_bottom": curr_open,
                })
                max_gap_size = max(max_gap_size, gap_size_pct)
                # 最近缺口距当前价
                distance = abs(latest_close - prev_low) / max(prev_low, 0.01) * 100
                latest_gap_distance = min(latest_gap_distance, distance)
    
    return {
        "unfilled_gap_count": len(unfilled_gaps),
        "max_gap_size_pct": round(max_gap_size, 2),
        "latest_gap_distance_pct": round(latest_gap_distance, 2) if unfilled_gaps else 99.0,
    }
```

### [F-04] 时间效率因子 (time_efficiency_factor)

**价值**：同等回撤天数下，跌幅小的更健康——说明有资金在承接，没有出现恐慌性抛售。

**数据来源**：现有 metrics（`drawdown_from_board_pct` / `retracement_days`）

```python
def evaluate_time_efficiency_factor(metrics: CandidateMetrics) -> float:
    """
    时间效率因子：回撤速度 = 回撤深度 / 回撤天数。
    
    回撤速度快（一天跌 3%）→ 可能是恐慌抛售
    回撤速度慢（三天跌 3%）→ 有序回调，有人在接
    """
    if metrics.retracement_days <= 0:
        return 0.0
    
    drawdown_per_day = abs(metrics.drawdown_from_board_pct) / max(metrics.retracement_days, 1)
    
    score = 0.0
    if drawdown_per_day <= 0.8:
        score += 3.0   # 极慢回撤（非常健康）
    elif drawdown_per_day <= 1.5:
        score += 2.0   # 慢回撤（健康）
    elif drawdown_per_day <= 2.5:
        score += 1.0   # 正常回撤
    elif drawdown_per_day >= 5.0:
        score -= 1.5   # 急跌（恐慌可能）
    
    return round(_clamp(score, 0.0, 5.0), 2)
```

不需要新 metrics 字段——`drawdown_from_board_pct` 和 `retracement_days` 已存在于 `CandidateMetrics`。

### [F-05] 信号新鲜度因子 (signal_freshness_factor)

**价值**：同样是 buy_now，今天刚出现的比 3 天前出现的更值得关注。

**数据来源**：`context.confirmed_trade_date` vs `context.current_date`

```python
def evaluate_signal_freshness_factor(
    confirmed_trade_date: str,
    current_date: str,
) -> float:
    """
    信号新鲜度因子：信号出现天数越短越有操作价值。
    
    当天 → 3.0
    1 天前 → 2.0
    2 天前 → 1.0
    3 天前 → 0.5
    超过 3 天 → 0.0
    """
    if not confirmed_trade_date or not current_date:
        return 0.0
    
    try:
        from datetime import datetime
        confirmed = datetime.strptime(confirmed_trade_date[:10], "%Y-%m-%d")
        current = datetime.strptime(current_date[:10], "%Y-%m-%d")
        days_old = (current - confirmed).days
    except (ValueError, IndexError):
        return 0.0
    
    if days_old <= 0:
        return 3.0
    if days_old == 1:
        return 2.0
    if days_old == 2:
        return 1.0
    if days_old == 3:
        return 0.5
    return 0.0
```

不需要新 metrics 字段——信息来自外部上下文。

### [F-06] 板块信号密度因子 (sector_signal_density_factor)

**价值**：这是当前系统最大的 alpha 来源之一。同一板块内多只股票同时通过预筛选 = 板块效应确认 = 每只的置信度更高。

def _build_sector_density_context(

    strategy: str,

    sector_counts: dict[str, int] = {}

    for sector, count in sector_counts.items():
        if count >= 6:
            scores[sector] = 3.0
        elif count >= 4:
            scores[sector] = 2.0
        elif count >= 2:
            scores[sector] = 1.0
        else:
            scores[sector] = 0.0
    return scores

### [F-07] 板块资金流向因子 (sector_flow_factor)

**价值**：hot_industries 是事后总结（哪些板块最近涨停多），资金流向是当日先行指标（钱正在往哪里走）。

**数据来源**：akshare `stock_sector_fund_flow_rank()`

**文件**：`backend/app/services/low_buy/factor_external.py`（新建）

```python
"""
外部数据源因子。使用 akshare 获取数据，带缓存。
"""
import time
import logging
from typing import Any

logger = logging.getLogger(__name__)

# 板块资金流向缓存（会话级，跨请求复用）
_sector_flow_cache: dict[str, tuple[float, dict[str, float]]] = {}
_SECTOR_FLOW_CACHE_TTL = 600  # 10 分钟


def resolve_sector_flow_ranks() -> dict[str, float]:
    """获取当日板块资金净流入排名。返回 {板块名: 排名分}。"""
    now = time.monotonic()
    cache_key = "daily"
    
    if cache_key in _sector_flow_cache:
        expires_at, cached = _sector_flow_cache[cache_key]
        if expires_at > now:
            return cached
    
    try:
        import akshare as ak
        df = ak.stock_sector_fund_flow_rank(indicator="今日", sector_type="行业资金流")
    except Exception as exc:
        logger.warning("sector fund flow fetch failed: %s", exc)
        return {}
    
    if df is None or df.empty:
        return {}
    
    # 按主力净流入排序，取前 10 名给满分
    df_sorted = df.sort_values("主力净流入-净额", ascending=False)
    total = len(df_sorted)
    ranks: dict[str, float] = {}
    for idx, (_, row) in enumerate(df_sorted.iterrows()):
        name = str(row.get("名称", ""))
        if not name:
            continue
        # 前 10% 满分 3.0，其余线性衰减
        percentile = idx / max(total, 1)
        if percentile <= 0.1:
            score = 3.0
        elif percentile <= 0.3:
            score = 2.0 - (percentile - 0.1) / 0.2 * 1.0
        elif percentile <= 0.5:
            score = 1.0 - (percentile - 0.3) / 0.2 * 0.5
        else:
            score = 0.0
        ranks[name] = round(max(0.0, score), 2)
    
    _sector_flow_cache[cache_key] = (now + _SECTOR_FLOW_CACHE_TTL, ranks)
    return ranks


def evaluate_sector_flow_factor(
    sector_name: str,
    sector_flow_ranks: dict[str, float],
) -> float:
    """板块资金流向因子。"""
    if not sector_name or not sector_flow_ranks:
        return 0.0
    
    # 精确匹配
    if sector_name in sector_flow_ranks:
        return sector_flow_ranks[sector_name]
    
    # 模糊匹配：板块名可能包含/不包含"行业"后缀
    for name, score in sector_flow_ranks.items():
        if sector_name in name or name in sector_name:
            return score * 0.8  # 模糊匹配打 8 折
    
    return 0.0
```

### [F-08] 大单流向因子 (big_order_flow_factor)

**价值**：区分机构行为 vs 散户行为。回撤期间大单净流入 = 机构在低吸。小单净流入 = 散户在接盘。

**数据来源**：akshare `stock_individual_fund_flow(stock, market)`

**可靠性说明**：东方财富资金流向数据基于逐笔成交推断，非交易所官方数据，精度有限。此因子权重应低于其他因子。

**文件**：`backend/app/services/low_buy/factor_external.py`（追加）

```python
_big_order_cache: dict[str, tuple[float, dict[str, float]]] = {}
_BIG_ORDER_CACHE_TTL = 300  # 5 分钟


def resolve_big_order_flow(
    symbol: str,
    retracement_days: int,
) -> dict[str, float]:
    """
    获取个股近期大单流向特征。
    
    返回 {
        "big_order_net_inflow_ratio": 大单净流入占比,
        "super_big_net_inflow_ratio": 超大单净流入占比,
        "retail_net_inflow_ratio": 小单净流入占比,
    }
    """
    now = time.monotonic()
    if symbol in _big_order_cache:
        expires_at, cached = _big_order_cache[symbol]
        if expires_at > now:
            return cached
    
    market = "sh" if symbol.startswith(("6", "5", "9")) else "sz"
    if symbol.startswith("8"):
        market = "bj"
    
    try:
        import akshare as ak
        df = ak.stock_individual_fund_flow(stock=symbol, market=market)
    except Exception as exc:
        logger.warning("big order flow fetch failed for %s: %s", symbol, exc)
        return {}
    
    if df is None or df.empty:
        return {}
    
    # 取最近 retracement_days + 3 天的数据
    recent = df.tail(max(retracement_days + 3, 5))
    
    result = {
        "big_order_net_inflow_ratio": round(
            recent["大单净流入-净占比"].astype(float).mean(), 2
        ),
        "super_big_net_inflow_ratio": round(
            recent["超大单净流入-净占比"].astype(float).mean(), 2
        ),
        "retail_net_inflow_ratio": round(
            recent["小单净流入-净占比"].astype(float).mean(), 2
        ),
    }
    
    _big_order_cache[symbol] = (now + _BIG_ORDER_CACHE_TTL, result)
    return result


def evaluate_big_order_flow_factor(
    symbol: str,
    retracement_days: int,
) -> float:
    """大单流向因子。机构低吸加分，散户接盘扣分。"""
    flows = resolve_big_order_flow(symbol, retracement_days)
    if not flows:
        return 0.0
    
    score = 0.0
    
    # 大单净流入（主力在吸）
    big_ratio = flows.get("big_order_net_inflow_ratio", 0)
    if big_ratio >= 5.0:
        score += 2.5
    elif big_ratio >= 2.0:
        score += 1.5
    elif big_ratio >= 0:
        score += 0.5
    
    # 超大单（机构专用通道）
    super_big_ratio = flows.get("super_big_net_inflow_ratio", 0)
    if super_big_ratio >= 5.0:
        score += 1.5
    
    # 小单净流入（散户在接 = 扣分）
    retail_ratio = flows.get("retail_net_inflow_ratio", 0)
    if retail_ratio >= 10.0:
        score -= 2.0  # 散户主导
    elif retail_ratio >= 5.0:
        score -= 1.0
    
    # 大单和超大单同时流入 → 确认信号
    if big_ratio >= 2.0 and super_big_ratio >= 2.0:
        score += 1.0
    
    return round(_clamp(score, 0.0, 5.0), 2)
```

注意：这是纯外部数据因子，不在 `_factor_scores(metrics)` 内调用——它在候选评估流程中通过单独的异步获取路径，因为需要网络请求。

### [F-09] 承接质量因子 (absorption_quality_factor)

**价值**：不是只看收盘位置，而是看盘中分时结构——上午砸盘下午拉回 vs 上午拉高下午砸盘，完全不同的含义。

**数据来源**：分时数据（akshare `stock_intraday` 或 existing market_data intraday bars）

**前置条件**：仅在盘中刷新时有效。盘后回测不适用。

```python
def evaluate_absorption_quality_factor(intraday_bars: list | None = None) -> float:
    """
    承接质量因子：盘中分时结构质量。
    
    仅在盘中刷新（有分时数据）时参与评分。
    盘后回测返回 0.0（不参与）。
    """
    if not intraday_bars or len(intraday_bars) < 30:
        return 0.0
    
    # 分成上午/下午两段
    # bars: list of {time, open, high, low, close, volume}
    mid = len(intraday_bars) // 2
    morning = intraday_bars[:mid]
    afternoon = intraday_bars[mid:]
    
    morning_low = min(b["low"] for b in morning)
    afternoon_low = min(b["low"] for b in afternoon)
    morning_high = max(b["high"] for b in morning)
    afternoon_high = max(b["high"] for b in afternoon)
    
    score = 0.0
    
    # 1. 尾盘 30 分钟资金方向
    last_30 = intraday_bars[-6:]  # 5 分钟线，最后 6 根 = 30 分钟
    if len(last_30) >= 3:
        tail_trend = last_30[-1]["close"] > last_30[0]["open"]
        tail_volume_up = sum(b["volume"] for b in last_30[-3:]) > sum(b["volume"] for b in last_30[:3])
        if tail_trend and tail_volume_up:
            score += 2.0  # 尾盘放量拉升
        elif tail_trend:
            score += 1.0  # 尾盘拉升但量不足
        elif not tail_trend and tail_volume_up:
            score -= 1.5  # 尾盘放量下跌
    
    # 2. 午盘低点高于早盘低点 → 承接在抬高
    if afternoon_low > morning_low * 1.002:
        score += 1.5
    
    # 3. 收盘价在当日振幅区间的上部 40%
    full_range = max(b["high"] for b in intraday_bars) - min(b["low"] for b in intraday_bars)
    close_position = (intraday_bars[-1]["close"] - min(b["low"] for b in intraday_bars)) / max(full_range, 0.01)
    if close_position >= 0.6:
        score += 1.5
    elif close_position <= 0.3:
        score -= 1.0
    
    return round(_clamp(score, 0.0, 5.0), 2)
```

### [F-10] 价格结构质量因子 (price_structure_factor)

**价值**：回撤不是无序下跌。好的回撤结构是"低点逐步抬高"或"在支撑位附近横盘"，坏的结构是"连续创新低"。

**数据来源**：`post_board` 中每日 `low` 序列

```python
def evaluate_price_structure_factor(metrics: CandidateMetrics) -> float:
    """
    价格结构质量因子：回撤期的价格轨迹是否有序。
    
    有序 = 低点不再下移、在均线附近获得支撑
    无序 = 连续创新低、无有效支撑
    """
    score = 0.0
    
    # 连续创新低天数（越少越好）
    if metrics.consecutive_lower_lows == 0:
        score += 3.0  # 低点稳定
    elif metrics.consecutive_lower_lows <= 2:
        score += 1.5
    elif metrics.consecutive_lower_lows >= 5:
        score -= 2.0  # 趋势性下跌
    
    # 支撑位触碰次数（在均线附近止跌的次数）
    if metrics.support_touch_count >= 3:
        score += 2.0  # 多次在支撑位获得承接
    elif metrics.support_touch_count >= 1:
        score += 1.0
    
    # 回撤轨迹平滑度
    if metrics.retracement_smoothness >= 0.7:
        score += 2.0  # 平滑回撤（有序）
    elif metrics.retracement_smoothness <= 0.3:
        score -= 1.0  # 锯齿状（无序）
    
    return round(_clamp(score, 0.0, 5.0), 2)
```

**metrics 计算**（在 `candidate_metrics.py` 中扩展）：

```python
def _compute_price_structure(post_board: pd.DataFrame, ma10: float, ma20: float) -> dict:
    """计算回撤期价格结构质量。"""
    lows = [float(row["low"]) for _, row in post_board.iterrows()]
    closes = [float(row["close"]) for _, row in post_board.iterrows()]
    
    # 连续创新低天数
    consecutive_lower_lows = 0
    for i in range(1, len(lows)):
        if lows[i] < lows[i - 1] * 0.998:
            consecutive_lower_lows += 1
        else:
            break  # 一旦不创新低就停止计数
    
    # 支撑位触碰次数（收盘价接近 MA10 或 MA20 且当日最低价明显低于收盘价 = 探底回升）
    support_touch_count = 0
    for i in range(len(post_board)):
        close = closes[i]
        low = lows[i]
        if abs(close - ma10) / max(ma10, 0.01) <= 0.02 and (close - low) / max(close, 0.01) >= 0.01:
            support_touch_count += 1
        elif abs(close - ma20) / max(ma20, 0.01) <= 0.025 and (close - low) / max(close, 0.01) >= 0.015:
            support_touch_count += 1
    
    # 回撤轨迹平滑度：收盘价的路径与直线回撤的偏离度
    retracement_smoothness = _compute_path_smoothness(closes)
    
    return {
        "consecutive_lower_lows": consecutive_lower_lows,
        "support_touch_count": support_touch_count,
        "retracement_smoothness": round(retracement_smoothness, 3),
    }


def _compute_path_smoothness(prices: list[float]) -> float:
    """计算价格路径的平滑度。1.0 = 完美直线，0.0 = 高度锯齿。"""
    if len(prices) < 3:
        return 0.5
    # 线性回归残差
    n = len(prices)
    x_mean = (n - 1) / 2.0
    y_mean = sum(prices) / n
    numerator = sum((i - x_mean) * (prices[i] - y_mean) for i in range(n))
    denominator = sum((i - x_mean) ** 2 for i in range(n))
    if denominator == 0:
        return 0.5
    slope = numerator / denominator
    intercept = y_mean - slope * x_mean
    residuals = sum((prices[i] - (slope * i + intercept)) ** 2 for i in range(n))
    rmse = (residuals / n) ** 0.5
    total_range = max(prices) - min(prices)
    if total_range == 0:
        return 1.0
    # R² 近似
    r_squared = 1.0 - residuals / max(sum((p - y_mean) ** 2 for p in prices), 0.0001)
    return max(0.0, min(1.0, r_squared))
```

### [F-11] 事件风险因子 (event_risk_factor)

**价值**：候选股在回撤期间是否有公告（业绩预告、减持、问询函等）。有负面公告的票应扣分或排除。

**数据来源**：akshare `stock_notice_report()`（已在 `market/sectors.py` 中使用）

```python
_stock_notice_cache: dict[str, tuple[float, bool]] = {}
_STOCK_NOTICE_CACHE_TTL = 1800  # 30 分钟


def resolve_stock_notice_risk(symbol: str) -> bool:
    """
    检查个股近期是否有负面公告。
    返回 True = 有风险需要关注。
    """
    now = time.monotonic()
    if symbol in _stock_notice_cache:
        expires_at, has_risk = _stock_notice_cache[symbol]
        if expires_at > now:
            return has_risk
    
    try:
        import akshare as ak
        df = ak.stock_notice_report(symbol=symbol)
    except Exception:
        _stock_notice_cache[symbol] = (now + _STOCK_NOTICE_CACHE_TTL, False)
        return False
    
    if df is None or df.empty:
        _stock_notice_cache[symbol] = (now + _STOCK_NOTICE_CACHE_TTL, False)
        return False
    
    # 检查近期公告标题中的负面关键词
    negative_keywords = [
        "减持", "问询", "警示", "处罚", "亏损", "退市",
        "立案", "调查", "暂停上市", "终止", "预亏",
        "股东减持", "质押", "冻结", "司法", "诉讼",
    ]
    recent = df.head(10)
    title_col = next((c for c in recent.columns if "标题" in str(c) or "title" in str(c).lower()), None)
    
    has_risk = False
    if title_col:
        for _, row in recent.iterrows():
            title = str(row[title_col])
            if any(kw in title for kw in negative_keywords):
                has_risk = True
                break
    
    _stock_notice_cache[symbol] = (now + _STOCK_NOTICE_CACHE_TTL, has_risk)
    return has_risk


def evaluate_event_risk_factor(symbol: str) -> float:
    """
    事件风险因子：近期有负面公告 = 扣分。
    注意：这是安全因子，默认返回 0（不扣分），有风险时返回负向扣分。
    但因子系统只取 >0 的值，所以改为返回"安全得分"。
    """
    has_risk = resolve_stock_notice_risk(symbol)
    if has_risk:
        return 0.0  # 有风险不加分
    return 1.0  # 无风险加 1 分（轻微正向）
```

## 四、因子得分体系设计原则

### 4.1 归一化规则

所有因子返回 `0.0 ~ 5.0` 范围。`0.0` = 该因子不适用或不加分，`5.0` = 该维度满分。

当前上限：`factor_bonus = min(5.0, sum(factor_scores.values()))`。扩展到 11 个因子后，需要调高上限：

### 4.2 因子独立性检查

在因子系统上线前，需要验证因子间相关性。如果两个因子相关性 > 0.8，应该合并或去掉一个。

预期检查点（基于设计逻辑，非数据验证）：
- shrink_quality ↔ volatility_regime：中等相关（缩量好的回撤通常波动率也在收敛）→ 0.4-0.6
- gap_risk ↔ price_structure：弱相关（跳空缺口多和价格结构差是不同的维度）
- sector_density ↔ sector_flow：中等相关（资金流入了才会有板块效应）→ 0.3-0.5
- deep_pullback ↔ time_efficiency：弱相关

### 4.3 因子权重

在 `candidate.py` 的 `_evaluate_candidate` 中，当前所有因子等同权重（简单加和）。未来可以在 `LowBuyThresholds` 中为每个因子配置权重：

|---|---|---|
| sector_flow | ak.stock_sector_fund_flow_rank | 会话级 10 分钟 |
| big_order_flow | ak.stock_individual_fund_flow | 单票 5 分钟 |
| event_risk | ak.stock_notice_report | 单票 30 分钟 |

**集成路径**：
这些因子不适合在 `_factor_scores(metrics)` 内同步调用（会阻塞）。应在候选评估外层异步预获取：

```python
# screening.py 中
# 在逐候选评估前，批量预获取外部数据
external_factors = await _prefetch_external_factors(ranked_pool)

# 传入每个候选
for item in ranked_pool:
    factor_scores = self._factor_scores(metrics, context)
    # 追加外部因子
    ext = external_factors.get(item.symbol, {})
    factor_scores["sector_flow_factor"] = ext.get("sector_flow", 0)
    factor_scores["big_order_flow_factor"] = ext.get("big_order", 0)
```
