# 新增主力模型相关策略回测总结

生成日期：2026-05-28

## 结论

本轮回测和链路核对完成。新增主力模型的样本外验证结果较强，但生产放行仍不通过，原因是 Shadow 样本还未达到最小 300 条观测和 120 条已结算样本闸门。

相关低吸策略的 24 个月窗口回测显示：确定买入信号具备一定正期望，但全信号合计胜率偏低，不能直接作为生产放行依据。后续应继续使用市场状态、行业强弱和 Shadow 观测过滤，而不是调参追逐本次回测表现。

线上 Shadow 为 0 的根因已经定位：生产刷新优先走 Go 扫描物化路径，成功后直接返回，绕过了 Python 参考筛选里的 `record_main_force_shadow` 写入。已修复为 Go 物化成功后自动触发主力模型 Shadow warmup，并优先读取当天已物化候选补写观测；本地验证已从 0 增至 2 条观测。后续部署后需要随每日刷新继续累积，达到门槛前仍保持只读观察。

个别策略“总收益率非常夸张”的根因也已定位：旧报告把每一条信号按全仓逐笔复利串联，忽略同一天多信号和资金占用，属于诊断口径，不是真实组合收益。已改为“每日信号等权投入 1 单位资金”的资金受限收益；旧逐信号复利值保留在 `diagnostic_compound_return_pct`，只用于发现信号密度过高，不作为收益结论。

## 防未来函数与防过拟合控制

- 数据窗口固定为 2024-05-28 至 2026-04-28，低吸回测实际可评估区间为 2024-05-28 至 2026-04-21，保留 5 个交易日 forward window。
- 主力模型验证使用时间序列切分：train 12 个月、valid 3 个月、test 3 个月，purged gap 10 天，禁止随机切分。
- 主力模型 temporal guard 通过：`max_source_date <= as_of_date < label_start_date`，特征日期不晚于信号日，标签从信号日之后开始。
- 本轮没有改参数、没有新增阈值、没有启用 prefilter override；低吸策略使用现有 `candidate_exit_plan`。
- 回测模式为 `isolated/fast`，不写生产物化表，不把回测候选反灌到生产结果。
- 低吸回测股票池排除了 `board_date >= trade_date` 的候选，避免把当日或未来涨停启动信息用于历史信号。
- 总收益/年化收益采用资金受限口径；逐信号无资金约束复利仅为诊断字段，避免收益展示层过拟合信号数量。
- 参数稳定性报告标记 `production_parameter_change_allowed=false`，本轮不允许基于回测自动变更生产参数。

## Shadow 样本修复方案

- 修复入口：`refresh_latest_low_buy_materialization` 在 Go 扫描成功后会调用 `warm_main_force_shadow_observations`。
- 候选来源：优先读取当天 `low_buy_result_snapshots` 已物化候选补写 Shadow，减少实时行情源失败导致样本为 0 的风险；物化候选不足时再走 Python 参考筛选兜底。
- 写入范围：只针对 `main_force_model_allowed_strategies` 中允许的策略，且仅记录当前筛选观测，不写历史回测样本。
- 风险边界：Shadow 仍为 `readonly_shadow`，不参与排名、不生成自动交易、不改变生产参数。
- 本地验证：`local_shadow_warmup_verification` 从 0 增至 2 条观测；线上部署后需等待日常刷新继续积累。
