### 2.2 `action` / `effective_action` / `is_actionable` 三字段语义

**定义**：

```
字段              来源                  含义                          使用者
──────────────────────────────────────────────────────────────────────────────
action             量化引擎原始判断       纯信号，不受费用/弹性影响        Agent、回测引擎、信号复盘
effective_action   费用过滤后建议         费用+高质量弹性过滤后的建议      前端信号卡片、App
is_actionable      综合可执行判断         effective_action != "hold"      Web/App 操作按钮、
                                         && action != "hold"             模拟盘自动交易
```

**`effective_action` 映射规则**（精确到条件）：

| 原始 `action` | 费用条件 | 弹性条件（仅 data_quality==ok） | `effective_action` | `is_actionable` |
|--------------|---------|-------------------------------|-------------------|-----------------|
| `"hold"` | — | — | `"hold"` | `false` |
| `"positive_t"` | `breakeven_pct > max_breakeven_pct` | — | `"hold"` | `false` |
| `"positive_t"` | `net_profit_pct < min_net_profit_pct` | — | `"hold"` | `false` |
| `"positive_t"` | 通过 | `elasticity_score < min_elasticity_score` | `"positive_t"` | `false` |
| `"positive_t"` | 通过 | 通过 或 stale | `"positive_t"` | `true` |
| `"negative_t"` | `breakeven_pct > max_breakeven_pct` | — | `"hold"` | `false` |
| `"negative_t"` | `net_profit_pct < min_net_profit_pct` | — | `"hold"` | `false` |
| `"negative_t"` | 通过 | `elasticity_score < min_elasticity_score` | `"negative_t"` | `false` |
| `"negative_t"` | 通过 | 通过 或 stale | `"negative_t"` | `true` |

**关键规则**：
- 弹性数据 `data_quality == "stale"` → 不参与降级，仅 UI 提示
- 弹性数据 `data_quality == "ok"` 且 score < 阈值 → `is_actionable = false`（仍保留原始方向）
- `action` 字段永不被修改

**消费端精确到文件**：

| 消费端 | 文件 | `action` | `effective_action` | `is_actionable` |
|-------|------|---------|--------------------|-----------------|
| Web 信号卡片 | `frontend/src/features/analysis/*.tsx` | tooltip 详情 | 卡片标题方向 | 按钮 disabled + 文案"不建议操作" |
| App 信号卡 | `app_mobile/low_buy.py` + App 客户端 | 原始信号文字 | 可执行建议文字 | 操作入口隐藏 |
| Agent 报告 | `agent_notification_service.py` | 引用原始判断 | 引用"可执行建议" | 不单独展示 |
| 模拟盘自动交易 | `paper/scheduler.py:383-384` run_cycle | 不使用 | 不使用 | **`false` → 跳过该信号，不生成委托** |
| 回测引擎 | backtest runner | 用于绩效统计 | 不使用 | 不使用 |
| Feishu/Hermes | `feishu_card_builder.py`, `hermes_workflow_runner.py` | 不包含（使用 digest） | **不包含**（保持 digest 兼容） | 不包含 |

### 4.2 新增 `TradeCostEstimate` dataclass + `attach_trade_costs()`

不改 `TradePlan`。在 `quant_engine_execution.py` 新增 `attach_trade_costs()`，返回 `TradeCostEstimate`。

`min_shares_suggestion` 计算公式：`ceil(5.0 / (price * actual_commission_rate) / 100) * 100`，其中 `actual_commission_rate` 从 `calculate_fee()` 获取（股票 ~0.00025，ETF 可能不同），**不使用硬编码**。

验收用例（固定）：

| 场景 | 输入 | 预期 `min_shares_suggestion` |
|------|------|---------------------------|
