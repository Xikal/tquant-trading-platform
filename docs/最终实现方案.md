### [F-7] 增加 CVaR 指标 ⭐ 视频建议 #2

**文件**：`backend/app/services/low_buy/performance.py`

新增函数：

```python
def compute_cvar(returns: list[float], confidence: float = 0.95) -> float:
    """
    CVaR（条件在险价值）：最差 (1-confidence)% 交易的均值亏损。
    
    例如 confidence=0.95 时，取最差的 5% 交易，计算它们的平均收益率。
    这比 avg_loss 更能反映极端情况下的真实风险。
    
    如果最差的 5% 只有 3 笔，则取最差的 3 笔的均值。
    """
    if not returns:
        return 0.0
    sorted_returns = sorted(returns)
    tail_count = max(1, int(len(sorted_returns) * (1 - confidence)))
    tail = sorted_returns[:tail_count]
    return sum(tail) / len(tail)
```

在 `compute_overall` 和 `compute_by_strategy` 的输出中增加 `cvar_5pct` 字段（最差 5% 交易的均值收益）。

在绩效 API 响应中暴露此指标。

在绩效面板中展示，旁边标注解释文字："最差 5% 交易的平均亏损"。

**验收**：
- 10 笔收益为 [5%, 3%, 1%, -1%, -2%, -3%, -5%, -7%, -10%, -15%] 的策略，CVaR(0.95) = (-15% + -10%) / 2 = -12.5%
- 而 avg_loss = (-1%-2%-3%-5%-7%-10%-15%) / 7 ≈ -6.1%
- CVaR 比 avg_loss 差一倍，揭示了尾部风险

### [F-8] 增加 PBO 检验 ⭐ 视频建议 #3

**文件**：`backend/app/services/low_buy/execution_backtest.py`（或新建 `pbo.py`）

新增函数：

```python
import random

def compute_pbo(
    real_sharpe: float,
    signal_series: list[bool],
    returns_series: list[float],
    n_permutations: int = 1000,
) -> dict:
    """
    PBO（Probability of Better Outcome）：策略是否真的优于随机。
    
    方法：
    1. 将信号序列随机打乱 n 次
    2. 每次打乱后，重新计算"伪策略"的夏普比率
    3. 统计伪策略中夏普 >= 真实夏普的比例
    4. PBO = 1 - 该比例（越高越好，> 0.9 可认为策略有真实 alpha）
    
    如果 PBO < 0.5，策略大概率是过拟合的噪声。
    """
    random.seed(42)
    pseudo_sharpes = []
    n = len(signal_series)
    
    for _ in range(n_permutations):
        shuffled_idx = list(range(n))
        random.shuffle(shuffled_idx)
        pseudo_signals = [signal_series[i] for i in shuffled_idx]
        # 用伪信号计算收益
        pseudo_returns = [
            returns_series[i] if pseudo_signals[i] else 0.0
            for i in range(n)
        ]
        pseudo_sharpe = _compute_sharpe(pseudo_returns)
        pseudo_sharpes.append(pseudo_sharpe)
    
    better_count = sum(1 for s in pseudo_sharpes if s >= real_sharpe)
    pbo = 1.0 - better_count / n_permutations
    
    return {
        "pbo": round(pbo, 4),
        "real_sharpe": round(real_sharpe, 4),
        "pseudo_sharpe_mean": round(sum(pseudo_sharpes) / len(pseudo_sharpes), 4),
        "pseudo_sharpe_95pct": round(sorted(pseudo_sharpes)[int(n_permutations * 0.95)], 4),
        "n_permutations": n_permutations,
        "verdict": "likely_overfit" if pbo < 0.5 else "potentially_valid" if pbo < 0.9 else "strong_evidence",
    }
```

在回测 API 响应中增加 PBO 结果。

在回测面板中展示 PBO 值，带颜色编码（红色 < 0.5，黄色 0.5-0.9，绿色 > 0.9）。

**注意**：PBO 计算需要信号序列和收益序列。当前 `execution_backtest.py` 的输出不直接包含逐日的信号/收益配对。需要增加中间数据输出或在回测过程中记录。

**验收**：
- 纯随机信号 → PBO < 0.1
- 有真实 alpha 的策略 → PBO > 0.9
- 过拟合的策略（参数在训练区间优化过）→ PBO 在 0.3-0.6

### [F-9] 引入策略级凯利仓位 ⭐ 视频建议 #4

**文件**：新建 `backend/app/services/low_buy/position_sizing.py`

```python
from dataclasses import dataclass

@dataclass
class KellyPosition:
    """凯利仓位计算结果"""
    full_kelly: float    # 全凯利仓位比例
    half_kelly: float    # 半凯利（推荐实盘使用）
    quarter_kelly: float # 四分之一凯利（保守）
    win_rate: float
    avg_win_pct: float
    avg_loss_pct: float
    expected_value: float

def compute_kelly_position(
    win_rate: float,
    avg_win_pct: float,
    avg_loss_pct: float,
    max_position_pct: float = 0.25,  # 单策略硬上限 25%
    min_position_pct: float = 0.05,  # 最低 5%
) -> KellyPosition:
    """
    凯利公式：f = (b*p - q) / b
    
    b = 盈亏比 = avg_win / abs(avg_loss)
    p = 胜率
    q = 1 - p
    
    半凯利 = full_kelly / 2（平衡增长与波动）
    """
    if avg_loss_pct >= 0 or avg_win_pct <= 0:
        return KellyPosition(0, 0, 0, win_rate, avg_win_pct, avg_loss_pct, 0)
    
    b = avg_win_pct / abs(avg_loss_pct)
    q = 1.0 - win_rate
    
    full_kelly = (b * win_rate - q) / b
    full_kelly = max(0.0, min(full_kelly, max_position_pct))
    
    half_kelly = full_kelly / 2.0
    quarter_kelly = full_kelly / 4.0
    
    if half_kelly < min_position_pct and full_kelly > 0:
        half_kelly = min_position_pct
    
    ev = win_rate * avg_win_pct - q * abs(avg_loss_pct)
    
    return KellyPosition(
        full_kelly=round(full_kelly, 4),
        half_kelly=round(half_kelly, 4),
        quarter_kelly=round(quarter_kelly, 4),
        win_rate=win_rate,
        avg_win_pct=avg_win_pct,
        avg_loss_pct=avg_loss_pct,
        expected_value=round(ev, 4),
    )
```

在 `priority_scoring.py` 中，将各策略的滚动绩效（胜率、平均盈利、平均亏损）传入 `compute_kelly_position`，用半凯利替代当前的固定 `position_multiplier`。

**效果示例**：

| 策略 | 胜率 | 平均盈利 | 平均亏损 | 当前仓位 | 半凯利仓位 |
|---|---|---|---|---|---|
| first_board | 58% | +2.1% | -1.5% | 统一打折 | 15% |
| volume_shrink | 62% | +1.8% | -1.2% | 统一打折 | 19% |
| divergence_consensus | 38% | +4.5% | -1.8% | 统一打折 | 12% |

注意：divergence_consensus 胜率只有 38%，但盈亏比 2.5:1，凯利仓位反而给到了 12%——这就是视频一的核心理念：**低胜率高盈亏比的策略值得更高的仓位**。

**验收**：
- 胜率 50%、盈亏比 2:1 → 半凯利 ≈ 12.5%
- 胜率 70%、盈亏比 0.8:1 → 凯利 = 0（无正期望）
- 胜率 90%、盈亏比 2:1 → 半凯利 ≈ 21%（接近上限）

```python
def simulate_liquidity_crisis(
    filled_signals: list[dict],
    crisis_ratio: float = 0.05,  # 5% 持仓遇到流动性危机
    crisis_extra_loss_pct: float = -25.0,  # 连续跌停额外亏损 -25%
) -> dict:
    """
    模拟极端流动性枯竭场景：
    随机选取 crisis_ratio 比例的持仓，假设它们遇到连续跌停无法卖出，
    每笔额外亏损 crisis_extra_loss_pct。
    
    返回修正后的总体绩效指标。
    """
    n_crisis = max(1, int(len(filled_signals) * crisis_ratio))
    crisis_indices = random.sample(range(len(filled_signals)), n_crisis)
    
    # 克隆信号数据
    adjusted = [dict(s) for s in filled_signals]
    for i in crisis_indices:
        adjusted[i]["net_return_pct"] = adjusted[i].get("net_return_pct", 0) + crisis_extra_loss_pct
    
    return recompute_performance(adjusted)
```
