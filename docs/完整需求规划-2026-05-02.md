## 四、策略体系

### 4.1 策略分层定义（终版）

```
Layer 0 → 核心生产（优先榜主力，全权重独立排名）
  first_board          — 首板回调
  classic_retrace      — 原始低吸法
  volume_shrink        — 量能低吸
  divergence_consensus — 分歧转一致

Layer 1 → 辅助生产（优先榜补充，0.65x 权重，不给 buy_now）
  ma_support                — 均线支撑
  breakout_support          — 位置支撑
  late_session_strong_support — 收盘强势承接（不给 buy_now，仅 near_entry）

Layer 2 → 研究验证（仅研究面板，不参与优先榜）
  limit_up_breakout_retrace          — 涨停突破回踩
  core_midcap_vwap_ma5_retrace      — 中军 VWAP/均线回踩
  sector_mainline_first_divergence_low_buy — 主线首分歧低吸

Layer F → 因子（不对用户展示，仅加分）
  deep_pullback_factor   — 深度低吸 risk_aware_bonus
  trend_rebound_factor   — 趋势龙回头 momentum_bonus
```

### 5.2 新增因子需求

#### REQ-FACTOR-001：北向资金流向因子 `north_flow_factor`

**权重**：1.0（与 sector_density 同级）
**数据源**：东方财富沪深港通资金流向 API（免费）
**逻辑**：过去 3/5/10 日北向资金连续净流入状态评分。连续净流入 → 正分；流向反转（连续流入转流出）→ 负分。对权重股（沪深 300 成分股）加成效果更强。
**适用策略**：`first_board`、`ma_support`、`classic_retrace`
**文件**：新建 `backend/app/services/low_buy/north_flow_factor.py`

#### REQ-FACTOR-002：龙虎榜游资活跃度因子 `dragon_board_factor`

**权重**：0.8
**数据源**：东方财富龙虎榜 API（免费）
**逻辑**：近 5 日上龙虎榜 + 买一为知名游资席位 + 买入占比 > 卖出占比 → 正分。"机构专用"席位上榜 → 额外加分。游资买入均价与当前价格的偏离度 → 辅助判断支撑位。
**适用策略**：`classic_retrace`、`volume_shrink`、`first_board`
**文件**：新建 `backend/app/services/low_buy/dragon_board_factor.py`

#### REQ-FACTOR-003：涨停板质量因子 `limit_up_quality_factor`

**权重**：0.9
**数据源**：现有涨停板数据 + 封单量 / 流通市值比（东方财富 API）
**逻辑**：评估近期涨停的质量——封板时间（越早越好）、开板次数（越少越好）、封单强度（封单手数 / 流通股本）、涨停后次日表现（高开/平开/低开）。对 `first_board` 策略的"首板"质量做精细区分。
**适用策略**：`first_board`、`divergence_consensus`
**文件**：新建 `backend/app/services/low_buy/limit_up_quality_factor.py`

#### REQ-FACTOR-004：集合竞价强度因子 `pre_market_auction_factor`

**权重**：0.6
**数据源**：盘中 9:25 行情快照（开盘价、集合竞价成交额、未匹配量）
**逻辑**：集合竞价量比（竞价成交额 / 前 5 日均额）、跳空幅度（开盘价 vs 前收盘）、未匹配量方向（大量买单未匹配 → 强势）。日内激活时间窗口：9:30-10:00。
**适用策略**：`late_session_strong_support`、`first_board`
**文件**：新建 `backend/app/services/low_buy/pre_market_auction_factor.py`

#### REQ-FACTOR-005：融资余额变化因子 `margin_balance_factor`

**权重**：0.5
**数据源**：东方财富融资融券 API（免费但限频）
**逻辑**：过去 5 日融资余额变化趋势。连续增加 → 杠杆资金看多；骤降 > 5% → 恐慌去杠杆，可能错杀反弹。需要区分"正常波动"和"异常变化"。
**适用策略**：`deep_pullback_factor`（作为错杀验证）、`trend_rebound_factor`
**文件**：新建 `backend/app/services/low_buy/margin_balance_factor.py`

#### REQ-FACTOR-006：大宗交易折溢价因子 `block_trade_premium_factor`

**权重**：0.4
**数据源**：东方财富大宗交易接口（免费）
**逻辑**：近 10 日大宗交易溢价率加权（按成交额加权）。溢价 > 2% → 正面；折价 > 5% → 负面（可能是清仓式减持）。区分"机构买入"和"机构卖出"方向。
**适用策略**：`breakout_support`、`ma_support`
**文件**：新建 `backend/app/services/low_buy/block_trade_factor.py`

#### REQ-FACTOR-007：业绩超预期因子 `earnings_surprise_factor`

**逻辑**：实际 EPS / 一致预期 EPS - 1。超预期 > 15% → 最强信号；超预期 5-15% → 中等；低于预期 → 负分。仅在财报公告后的 10 个交易日内激活。
**适用策略**：所有策略（作为通用催化剂加分）
**文件**：新建 `backend/app/services/low_buy/earnings_surprise_factor.py`

#### REQ-FACTOR-008：股东增减持因子 `insider_trade_factor`

**权重**：0.5（以负向风控为主）
**数据源**：东方财富公告接口（免费但有延迟）
**逻辑**：近 30 日内大股东/高管增持 → 正面（尤其多名高管同时）。大额减持计划公告 → 强负分（直接降低所有策略信号权重 50%）。此因子更多作为"反向过滤器"而非加分项。
**适用策略**：所有策略（通用风控）
**文件**：新建 `backend/app/services/low_buy/insider_trade_factor.py`

#### REQ-FACTOR-009：融券余额因子 `short_balance_factor`

**权重**：0.7（需新增数据接口后激活）
**数据源**：东方财富融资融券 API 的融券部分
**逻辑**：融券余额骤增 → 做空压力/套保需求增加；融券余额极低 → 无做空压力。对权重股更有效（融券标的有限）。

## 十三、验收标准

### 安全

- [ ] 空 `AUTH_SECRET_KEY` 时服务拒绝启动
- [ ] 所有 API 端点（`/readyz` 除外）在无 Bearer token 时返回 401
- [ ] 登录接口被限流（> 5 次/分钟触发 429）
- [ ] SSE 连接不将 token 暴露在 URL 中
- [ ] HTTPS 已配置并强制跳转

### 策略

- [ ] 优先榜仅显示核心 + 辅助层策略
- [ ] 每个策略有 PBO 过拟合概率值
- [ ] PBO > 0.3 的策略在面板中标注警告
- [ ] 停牌股票不出现在候选列表
- [ ] 涨停股票在买入信号中标记为"不可执行"

### 代码质量

- [ ] `grep "except Exception:\s*(pass|$)"` 返回零结果
- [ ] `grep "float(Decimal"` 在 paper/ 下返回零结果
- [ ] `low_buy/` 目录 ≤ 20 个 .py 文件
- [ ] 所有后端测试通过（当前 174 个 + 新增）
- [ ] 前端 `npm run build` 通过且无 TS 错误

### 模拟盘

- [ ] 批量订单中途失败时无部分提交
- [ ] 100 笔交易后资产偏差 < 0.01 CNY
- [ ] T+1 锁仓股票当日不可卖出
- [ ] 连续 3 笔亏损触发熔断
- [ ] AutoTrader dry_run=true 时不创建实际订单

### Agent

- [ ] Agent 不能直接访问数据库
- [ ] Agent 的所有操作有审计日志
- [ ] `agent_enable_write_tools=false` 时 Agent 不能调用写入工具
- [ ] 飞书 @bot 持仓 返回正确持仓卡片

### 前端

- [ ] 监测页 30 只自选股轮询 ≤ 2 次请求/30s（而非 90 次）
- [ ] 未登录用户不显示模拟盘 tab
- [ ] App 端离线时展示缓存数据 + 时间戳
