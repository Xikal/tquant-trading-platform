# 板块核心中军回踩 VWAP / 5 日线策略方案

更新时间：2026-04-30

## 1. 策略定位

本策略做的是主线板块里的容量核心股，在短线回踩关键支撑后，博弈 1-2 天修复。

- 策略类型：主线中军 + VWAP/5 日线承接 + 短线修复
- 持股周期：1-2 个交易日
- 收益目标：1%-3%
- 风格目标：胜率优先，稳定性优先

核心原则：

> 买主线中军第一次健康回踩，卖次日修复。

本策略不是情绪小票打法，也不是中线趋势持仓。失败后必须快速退出。

## 2. 核心逻辑

主线板块中军通常有大资金参与，不容易像情绪小票一样极端 A 杀。当中军强趋势形成后，第一次回踩 VWAP、5 日线或 10 日线，如果板块仍是主线、个股缩量回踩、分时承接良好且趋势没有破坏，次日容易出现修复性冲高。

## 3. 市场与板块条件

### 3.1 市场条件

| 市场状态 | 操作 |
|---|---|
| 指数震荡 | 可做 |
| 主线明确 | 优先 |
| 指数小跌但主线强 | 可小仓 |
| 高位退潮 | 禁止 |
| 系统性杀跌 | 禁止 |

### 3.2 板块条件

必须满足：

| 条件 | 建议 |
|---|---|
| 板块为近期主线 | 最近 3-5 日强度靠前 |
| 板块成交额 | 高于 5 日均值 |
| 板块内有活口 | 龙头或强趋势股未破位 |
| 板块不是连续退潮 | 不能连续 2 日大跌 |
| 板块中军存在 | 有 1-3 只大成交核心股 |

## 4. 个股选择

### 4.1 中军定义

中军不是涨停最多的票，而是板块内成交额大、趋势稳、能代表大资金态度的核心股。

常见特征：

- 成交额大
- 市值相对更大
- 趋势连续
- 与板块指数高度相关
- 板块强时不缺席，板块弱时相对抗跌

### 4.2 基础条件

| 条件 | 建议 |
|---|---:|
| 成交额 | >= 5 亿 |
| 流通市值 | 80-1500 亿 |
| 价格趋势 | 5 日线、10 日线向上 |
| 相对强度 | 强于板块或不弱于板块 |
| 回踩次数 | 第一次或第二次回踩优先 |
| 跌幅 | -0.5% 到 -4% |
| 放量情况 | 回踩不能明显放量破位 |

### 4.3 排除条件

以下任一出现，放弃：

- 板块已经连续退潮。
- 个股放量跌破 5 日线且无法收回。
- 个股跌破 10 日线后继续走弱。
- 板块龙头跌停或核心股集体破位。
- 个股已经连续加速后出现爆量大阴。
- 回踩当天出现明显利空或监管风险。

## 5. 买点设计

### 5.1 VWAP 回踩买点

适合日内强势中军。

| 条件 | 要求 |
|---|---|
| 当日走势 | 冲高后回踩或震荡回踩 |
| VWAP | 回踩不破，或跌破后快速收回 |
| 分时 | 低点抬高 |
| 板块 | 同步企稳 |
| 买点 | 重新站上 VWAP 后回踩确认 |

优势：

- 买点更贴近日内资金成本。
- 失败后容易识别。
- 适合 1 日持有。

### 5.2 5 日线回踩买点

适合日 K 趋势中军。

| 条件 | 要求 |
|---|---|
| 趋势 | 5 日线向上 |
| 回踩 | 接近 5 日线，偏离 <= 1.5% |
| 量能 | 回踩缩量 |
| K 线 | 小阴、小阳、下影线优先 |
| 板块 | 主线未破 |
| 买点 | 收盘不破 5 日线，或次日收回 5 日线 |

优势：

- 胜率相对稳定。
- 适合 1-2 天修复。
- 比追涨安全。

### 5.3 10 日线防守买点

只适合强主线中军。

| 条件 | 要求 |
|---|---|
| 板块 | 强主线，尚未退潮 |
| 个股 | 前期涨幅较大但趋势未坏 |
| 回踩 | 第一次回踩 10 日线 |
| 承接 | 放量不破或缩量企稳 |
| 仓位 | 小于 5 日线买点 |

如果跌破 10 日线后无法快速收回，不做。

## 6. 卖出规则

### 6.1 止盈

| 情况 | 动作 |
|---|---|
| 次日冲高 1% | 可先减一部分 |
| 次日冲高 2%-3% | 标准止盈 |
| 次日冲高 5% | 大部分兑现 |
| 板块强修复 | 可保留少量到 T+2 |
| 冲高回落跌破 VWAP | 剩余退出 |

### 6.2 止损

| 情况 | 动作 |
|---|---|
| 跌破 5 日线并收不回 | 退出 |
| 跌破 VWAP 后持续弱 | 退出 |
| 板块中军集体破位 | 退出 |
| 放量大阴 | 退出 |
| 次日没有修复 | 退出 |

### 6.3 时间规则

| 时间 | 规则 |
|---|---|
| T+1 上午 | 有冲高优先卖 |
| T+1 收盘 | 不强则走 |
| T+2 | 最晚退出 |
| 强趋势例外 | 只有板块继续加强，才保留小部分 |

## 7. 参数建议

| 参数 | 建议值 |
|---|---:|
| 个股成交额 | >= 5 亿 |
| 板块成交放大 | >= 1.2 倍 |
| 距 5 日线 | -0.5% 到 +1.5% |
| 距 VWAP | -0.8% 到 +1.2% |
| 回踩跌幅 | -0.5% 到 -4% |
| 回踩量能 | 低于近 5 日均量或低于前一日 |
| 第一止盈 | +1% |
| 标准止盈 | +2%-3% |
| 强止盈 | +5% |
| 止损 | -2% 到 -3% |
| 最大持有 | 2 个交易日 |
| 单票仓位 | 6%-12% |

## 8. 评分模型

| 因子 | 分数 |
|---|---:|
| 板块主线强度 | 0-20 |
| 个股中军地位 | 0-20 |
| 趋势健康度 | 0-15 |
| VWAP / 5 日线承接 | 0-20 |
| 回踩缩量 | 0-10 |
| 相对板块强度 | 0-10 |
| 风险扣分 | -30 到 0 |

信号分层：

| 分数 | 动作 |
|---|---|
| >= 85 | 可执行 |
| 75-85 | 接近买点 |
| 60-75 | 观察 |
| < 60 | 放弃 |

## 9. 回测口径

必须统计：

- T 日是否为板块主线
- 个股是否为板块中军
- 入场位置：VWAP / 5 日线 / 10 日线
- T+1 开盘收益
- T+1 最高收益
- T+1 10:30 前最高收益
- T+1 收盘收益
- T+2 最高收益
- T+2 收盘收益
- 是否跌破 5 日线
- 是否跌破 VWAP
- 板块是否继续走强

核心门槛：

| 指标 | 目标 |
|---|---:|
| T+1 冲高 1% 命中率 | >= 70% |
| T+1 冲高 2% 命中率 | >= 55% |
| 净胜率 | >= 56% |
| 平均净收益 | >= 0.30%-0.50% |
| 止损率 | <= 10% |
| 最大持有 | <= 2 天 |
| 连续亏损 | <= 4 笔 |

## 11. 执行摘要

本策略只做主线中军的健康回踩，不做板块退潮下的抄底。核心是中军地位、趋势未坏、VWAP/5 日线承接和次日快速兑现。
