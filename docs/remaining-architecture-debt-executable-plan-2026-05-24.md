   - 目标：后续把高频独立页面逐步拆成真正的路由级页面组件，减少单壳层耦合。
   - 最小交付：先拆监控 / 情绪 / 选股宝典 / 分析 / 模拟盘 / 策略工作台 / 设置入口，保持其余页面仍走工作台壳层。
   - 验收：`MonitorRoute` / `EmotionRoute` / `AnalysisRoute` / `PlaybookRoute` / `PaperRoute` / `StrategyRoute` / `SettingsRoute` 已生成独立构建 chunk；工作台壳层不再负责这些高频入口的页面选择。

2. **Go BFF 从影子透传升级为真实聚合** ✅ 已完成最小交付
   - 当前状态：`monitor / paper` 两个 workspace 已改为 Go 侧并发聚合；manifest 也由 Go 侧直接返回。
   - 目标：把 workspace 聚合中最慢、最稳定的读取链路前移到 Go，减少 Python BFF 的串行查询压力。
   - 验收：Go BFF 直接返回聚合后的 workspace payload，而不是简单转发 Python 响应。
   - 后续：如需继续扩展，可再补 `strategy / settings` 的 Go 本地聚合，但这不属于当前最小交付阻塞项。

3. **分钟级行情存储升级为可分区的时序结构** ✅ 已完成最小交付

   - 最小交付：新增 minute-bar 分层表设计、增量写入、按日期分区策略和只读查询封装。
   - 验收：新增 `MinuteBarSnapshotStore` 负责增量写入与按交易日只读查询；现有接口保持兼容。
