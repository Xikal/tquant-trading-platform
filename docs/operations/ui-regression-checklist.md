# UI Regression Checklist

## 适用范围

用于页面布局、交互入口、主题色调整后的人工与自动化检查。

## 必跑命令

```bash
cd frontend
npm run build:web
```

如本地浏览器环境可用，继续执行：

```bash
../scripts/ui_smoke.sh
```

## 必看页面

- 实时监控
- 量化分析
- 选股宝典
- 研究复盘 / 策略工作台
- 模拟盘
- 系统配置
- 登录页
- 移动端壳页面

## 检查项

- 首屏无白屏、无明显横向溢出。
- 卡片、表格、图表不重叠。
- 红涨绿跌、风险色和禁用态语义保持一致。
- 长股票名、长 AI 文案、长错误信息不撑破布局。
- 小屏宽度下导航、弹窗、按钮仍可点击。
- 控制台无新增运行时错误。

## 约束

- 页面结构调整必须保持关键操作入口可见。
- 大范围 UI 调整必须先完成核心页面 smoke，再继续扩大范围。
